# ノートの画面（`features/notes/ui`）

ノートのタブ・右サイドバーのノート・入力欄の上の「ノート」の決まり。機能全体は `../CLAUDE.md`。

## 地図

| ファイル | 中身 |
|---|---|
| `tree/NoteTab.tsx`・`useNoteTab.ts` | ノートのタブ（右サイドバーも同じ）。欄を並べ、右のタブの欄 `notes`・URL の `?note=`・最後に表示したノート |
| `tree/NoteSection.tsx`・`useNoteSection.ts` | 欄 1 つ（1 プロジェクトの木。見出し `NoteSectionTools`・選択・作る・名前の変更・メニュー・整理のダイアログ） |
| `tree/noteDrag.ts`・`noteMoveModel.ts`・`noteTransfer.ts` | ドラッグ（運ぶものは欄とパス）・落とせる所・欄の間で動かす |
| `links/NoteChip.tsx`・`NoteChipSection.tsx` | 入力欄の上の「ノート」（共通のノートとこのプロジェクトの欄） |
| `commonNotes.ts` | 共通のノートの id・使えない理由・持ち主の名前・見えないプロジェクトの代わりのプロジェクト |
| `openNote.ts` | ノートを開く口（見えないプロジェクトのノートの開き先 `showHiddenProjectNote` もここ 1 つ） |

## 決まり

- 欄は `NoteSection` に欄のプロジェクトと開く関数・探す文・選んでいる欄・「〜へ移す」の行き先を渡すだけで描く（どの画面かを持たない）。ノートのタブはいちばん上に共通のノート、その下にいまのプロジェクト。
- 共通のノートは見えないプロジェクトのノート。タブ・別ウィンドウ・書きかけはそのプロジェクトの id で動く。その画面はないので、画面を移る所（開く・新しいチャット）は `screenProjectFor` でいま見ているプロジェクトにする。
- 共通のノートの id は `useCommonNotes`（`GET /api/notes/defaults`。`settings`・`project` の知らせで読み直す）。使えなければ欄に理由の文だけ、分かるまでは欄を出さない。名前は `noteOwnerName`（見えないプロジェクトの `name` を画面に出さない）。
- 選んでいる行は欄ごと。押した欄が選んでいる欄になり、ほかの欄は選んだ行を外す。キー操作はピントのある木が受ける。
- 欄の間はドラッグと右クリックの「〜へ移す」で、1 つずつ順に `to_project_id` 付きで動かす（ノートのチャットごと）。動かす前に書きかけを聞き、断られたらそこで止めて理由を出す。動かしたら `followMovedNote` がタブ・覚えた選択と開いているフォルダ・別ウィンドウ（`noteMoved`）を行き先へ付け替える。
- 開いているフォルダ（`useNoteFolders`）とドラッグの決まりは、欄の木と入力欄の上の木で共通。

## 落とし穴

- 右のタブの欄の「入れ替える」確かめは、入れ替えられるタブのプロジェクトで聞く（共通のノートのタブのこともある）。
- 最後に表示したノート（`selected`）はそのプロジェクトのノートだけを覚える（共通のノートのタブは開き直さない）。
- テスト: `tree/noteMoveModel.test.ts`・`notePanel.test.ts`・`openNote.test.ts`。
