# 別ウィンドウ（`features/popout`）

チャットの画面の右の欄のサブエージェント・変更・ファイル・メモ・DB クライアントと子チャット、左のサイドバー、右端のチャット欄とパネルのブラウザ・ターミナルのタブを、メインのウィンドウの外の別ウィンドウで見る（2 枚目の画面に差分・サブエージェントを置いたまま、1 枚目でチャットを続けるなど）。行き先・開き方・ウィンドウの間の知らせは `app/`（`popout.ts`・`windowBus.ts`・`PopoutApp.tsx`）、メインプロセスのウィンドウは `src/main/app/popouts.ts`。

- 開き方: タブをウィンドウの外へドラッグして離す（離した所に開く。`features/panel/CLAUDE.md` の「ペインの分割」）・右の欄のタブの右クリックの「別ウィンドウで開く」と、中身のいちばん上の見出しの行の右端のボタン（`PopOutTabButton`。サブエージェント・子チャット・メモ・変更・ファイルのどれでも同じ位置。`PanelTabPage` が `TabPageContext` で、そのタブを移す操作を中身に渡す。パネルの外・別ウィンドウの中では出さない。以前はタブの列の左の道具にあった）。開けるタブは種類の表の `popout`（`tabKinds.ts`。サブエージェント・子チャット・メモ・変更・ファイル・DB）で、開いたら右の欄からは閉じる（`panel/tabs/popOutTab.ts`。別ウィンドウへ移す）。Mac のアプリのときだけ（`canPopout`）。
- 行き先は URL のハッシュ `#/popout/<種類>?…`（`app/popout.ts` の `popoutPath` / `parsePopout`。純粋関数でテスト）。同じもの（変更は移るファイルを除いて同じ `popoutKey`）がもう開いていれば、メインプロセスがそのウィンドウを前に出し、変更の移るファイルは知らせ `popoutFocus` で渡す。ウィンドウの位置と大きさは、最後のものから少しずらして開く（アプリを閉じるまで覚える）。
- 画面: `main.tsx` が `#/popout/` なら App の代わりに `PopoutApp`（サーバーとのつながり・回答待ち・プロジェクトの色・会話の文字の大きさと、ウィンドウの中を探す ⌘F（ページの ⌘F。ファイル・メモはエディタの検索、ほかは右上の検索の欄。子チャットはチャットの中の検索が先に受け取る）だけ。サイドバー・通知・ショートカットを 2 つ動かさない）を描く。中身は右の欄と同じ部品: 変更・ファイルは `PopoutFiles`（`SideChanges` / `SideFileView`）、サブエージェントは `PopoutSubagent`（チャットの店の `useChatContent` ＋ `useChatView` でチャットの画面と同じ状態と操作を作り、`SubagentScreen` を描く。メインエージェントの書いている途中の返答は出さないので途中の文の口は読まず、返答中に描き直さない）、子チャット（`#/popout/chat?chat=`）は `PopoutChildChat`（チャットの画面の `ChatView` に、親を見る・親チャットに渡す ▾（依頼文を作ってもらう / 最新の答えを引用して渡す）・右の欄に戻すの帯 `ChildChatBar` を足す。作業の終わりの行の「親チャットに追加 ▾」もそのまま使える（コアに頼むので、別ウィンドウからでも同じ。入力欄に入れるときだけ、下の `childToParent` でメインに頼む）。`features/chat/CLAUDE.md` の「子チャット」）、メモ（`#/popout/memo?project=&path=&chat=`。開いたチャット（`chat`。メモのタブからなど、なければ付けない）ごとに別のウィンドウ。見出しの「「チャット名」に追加」と右に戻す先に使う）は `SideMemo`。DB クライアント（`#/popout/database?chat=&project=&worktree=`）は `DatabaseClient`（右の欄と同じ置き場所 `chat-<チャット>` なので、開いているタブはそのまま）。子チャットとメモは、設定の開き方が別ウィンドウのときに札などから直接開く（右の欄のときは、右の欄のタブから移す）。
- 子チャットのウィンドウの閉じ方（`src/main/app/popouts.ts`）: 最小化は閉じ方を聞かずに閉じる（子チャットは残る）。✕・⌘W はメインプロセスが閉じるのを止めて画面に知らせ（IPC の `windows.onCloseRequested`）、画面が閉じ方を聞いてから `windows.closeSelf` で閉じる（画面の `beforeunload` では止められない。利用者の操作がないページでは Chromium が無視する）。アプリの終了はウィンドウを閉じずにプロセスを終える（`src/main/CLAUDE.md` の「終了」）ので止めない。
- メインのウィンドウとのつながり（`app/windowBus.ts`。同じ出どころなので `BroadcastChannel`。`postToMainWindow` はメインのウィンドウを前にも出す）: 選択部分の「チャットに追加」・右クリックの、足す先のチャットの組・メモの添付はメインのそのチャットのチャット欄に足す（`fillComposer`。メモは `attachments` も。`addToChat`）、「流れで見る」は会話のその場所へ（`reveal`）、「動きで見る」は動きを開いてそのサブエージェントの行を強調する（`showActivity` → `focusActivity`）、「ファイルタブで開く」はメインのファイルタブで開く（`openProjectFile`）、返答の「メモに追加」のあとの「開く」・子チャットを右の欄に開く・「新しい子チャットで聞く」「子チャットを作成」でメインの右の欄に新しい子チャットのタブを開く（`askChild`。前は別ウィンドウにも聞くダイアログを置いていた）・子チャットから親へ（親を見る・親チャットに渡す・「親チャットに追加」の入力欄。入力欄の上の出どころの札 `composerHandoff` は localStorage なので別ウィンドウで書いてもメインに届く）・DB クライアントの「AI に聞く」で作った・聞いたチャットはメインのウィンドウで・「AI に渡す」の「新しいチャットで始める」はメインのプロジェクトのチャットのパネルに文と札を入れた新しいチャットのタブを（`openMemo` / `openChild` / `childToParent` / `openChat` / `openSeededChat`。App が `app/mainWindowMessages.ts` で受ける）。受け取るのは、チャットの知らせはメインの `ChatView`（`features/chat/pane/windowMessages.ts`。同じチャットを 2 つの欄で開いていても、見えている方に 1 回だけ）、ファイルタブ・メモのタブは App。ほかのサブエージェントの画面・変更・ファイルは、別ウィンドウのまま開く（`usePopoutFileLinks`）。
- 足す先のチャット: 右の欄と同じく、中身の右クリックの、足す先のチャットの名前の組と選んだときの「チャットに追加」で、開いたチャット（子チャットはいちばん上の親）に足せる（`SideScope`。`MainChatContext` と、ウィンドウ全体の `SideSelectionAttach`。`features/chat/CLAUDE.md` の「選択部分をチャットに追加」）。
- 表示の設定（会話の文字の大きさ・差分の表示のしかた・確認済みなど）は localStorage をメインのウィンドウと共有し、どのウィンドウで変えても `storage` の知らせでそろう（`lib/storage.ts`）。
- 右の欄に戻す: どの別ウィンドウにも「右の欄に戻す」（`PopoutDockButton`。上の細い帯 `.popout-bar`（何のウィンドウかの札と一緒に。`PopoutApp`）、子チャットは自分の帯 `ChildChatBar` の `extra`）。押すとメインのウィンドウに知らせ（`dockPopout`）、このウィンドウを閉じる（閉じ方は聞かない。メモの書きかけは `flushMemoDrafts` で残してから閉じるので、右の欄で未保存のまま続く）。メインのウィンドウでは `dockPopout.ts` が開き直す: 子チャット = いちばん上の親の右の欄（`openChildSide`）、サブエージェント = そのチャットの右の欄（チャットの画面が描かれてから `openSubagentSide`。子チャットのサブエージェントなら子チャットを開く）、変更・ファイル・DB = 結びついたチャット（子チャットなら、いちばん上の親）の右の欄、メモ = 開いたチャット（`chat`）の右の欄、なければいま見えているそのプロジェクトのチャットの右の欄（どちらもなければメモのタブ）。
- サイドバーの別ウィンドウ（`#/popout/sidebar`。アプリに 1 つ。利用者の依頼）: サイドバーの上の行の、閉じるボタンの左の「サイドバーを別ウィンドウで開く」（`AppWindow`。Mac のアプリのときだけ）で開き、メインのウィンドウのサイドバーは閉じる（移す）。中身は `PopoutSidebar`（メインのウィンドウと同じ `Sidebar` を、開閉・幅のつまみ・信号機ボタンの行なしでウィンドウいっぱいに。`.sidebar.sidebar-window`。細いウィンドウでもスマホの縦 1 列の規則は効かせない）。ウィンドウは細く（初め 300 × 820・最小幅 220）、位置と大きさはほかの別ウィンドウと別に覚える（`src/main/app/popouts.ts`）。上の帯の「左の欄に戻す」で、メインのウィンドウのサイドバーを開いてウィンドウを閉じる（`dockPopout` が `SIDEBAR_OPEN` を立てる）。✕ はそのまま閉じる（⌘B でメインのウィンドウのサイドバーを開ける）。
  - 画面とパネルの状態はメインのウィンドウの写し: 開いている間、別ウィンドウは `sidebarWindow`（開いた / 閉じた）を知らせ、メインのウィンドウ（`app/popoutHosts.ts` の `usePopoutHosts`）がいまの画面（`mainRoute`。開いているチャット・プロジェクトの強調・⌘N の作成先）とパネルの状態の写し（`mainPanels`。下書きの行・子チャットの行の「開いている」見た目。`features/panel/state/panelMirror.ts` の `sendPanelsWhileChanging`。50ms にまとめる）を送る。別ウィンドウの店は写しにし（`followMainPanels` → `panelStore` の `setPanelReplica`・`replacePanels`。写しの間は `dispatchPanel` が何もしない）、下書きの操作（開く・分けて開く・名前・固定・グループ・プロジェクト・削除）とチャットを分けて開くは `forwardPanelOp` でメインのウィンドウに頼む（`panelOp`。App が `mainWindowMessages.ts` で行う）。メインのウィンドウを読み込み直したら `mainWindowReady` で知らせ直してもらう。開くたびの番号は前と重ねない（「閉じた → 開いた」が続けて届いても送り直すように）。画面とつながりは `useMainWindowRoute`（チャット欄の別ウィンドウと共通）で、閉じたと知らせるのはウィンドウを閉じたとき（pagehide）だけ（開発時の StrictMode で effect の片付けが流れても知らせない）。画面が知らせられずに閉じたとき（落ちた・スクリプトで閉じた）も、メインプロセスの `windows.onPopoutClosed` でメインのウィンドウが移したままにしない。
  - 行を押す・新しいチャット・検索・設定・⌘⇧A・新しいプロジェクトはメインのウィンドウで（下の「画面を移る操作」）。
- 画面を移る操作とダイアログ（`app/popoutNavigation.ts` の `usePopoutForwarding`。どの別ウィンドウでも）: 別ウィンドウの中でリンク・`navigate`・`location.hash` で URL が別ウィンドウの行き先でなくなったら、URL を元に戻して（`forwardedNavigation`。純粋関数でテスト）メインのウィンドウでその画面を開く（`navigate`）。App が受けるイベント（設定・⌘⇧A・新しいプロジェクト・プロジェクトがないときの案内・全文検索・新しいチャット `START_NEW_CHAT_EVENT`・コマンドパレット `OPEN_COMMAND_PALETTE_EVENT`）は `appEvent` でメインのウィンドウに渡して起こし直す（中身はウィンドウをまたげる値だけ。新しいプロジェクトを作ったあとの処理も値 `after`）。別ウィンドウの `PopoutApp` は URL を画面として購読しない（前は `useHashRoute` で、別ウィンドウを開くたびに「最後に見ていた画面」を全プロジェクトに上書きしていた）。
- チャット欄の別ウィンドウ（`#/popout/side`。アプリに 1 つ。利用者の依頼）: チャット欄のタブの列の道具の「別ウィンドウで開く」（`PanelFrame` の `popOut`。`ProjectChat` が Mac のアプリのときだけ渡す）か、移したあとの右上のチャット欄の開閉・⌥⌘B（そのウィンドウを前に出す。`useProjectChat` の `inWindow`）。中身は `PopoutSideChat`（メインのウィンドウと同じ `ProjectChatPanel` をウィンドウいっぱいに。出すのはメインのウィンドウで開いているプロジェクトの欄で、全プロジェクトの画面ならサイドバーで選んでいるもので、チャットは出さない。欄はいつも開いておく）。ウィンドウは 480 × 820（最小幅 320）で、位置と大きさはサイドバーと同じく別に覚える。タブの列はドラッグ領域にせず、右端も空けず、メインのウィンドウのような 2 段にしないで、下のパネルと同じく 1 段に並べる（道具・タブ・新しいタブ・ペインの分割。利用者の依頼。2 段は上の段を信号機ボタンの行と分け合うためのもの。`.popout-side-chat`。`styles/panel/project-chat.css`）。
  - 状態は持ち主ごと移す（`features/panel/state/panelHandOff.ts`。写しではない）: 別ウィンドウが `sideWindow`（開いた。`holding` = もう持っている）を知らせると、メインのウィンドウはチャット欄のすべての欄（`side:*`）を取り出して（`takePanels`。タブの後始末はしない = ターミナルのシェルを止めない）`sidePanels` で渡し、自分ではチャット欄を描かない（`usePopoutHosts` の `sideHeld` → App が `ProjectChat` を描かない）。渡したあとに「開いた」がもう一度届いても渡し直さない（取り出したあとなので空を渡してしまう）。別ウィンドウは 1 回だけ受け取り（`adoptSidePanels`。3 秒で届かなければ空のまま描き、あとで届けば受け取る）、ターミナルのシェルの持ち主をこのウィンドウにする（`claimTerminal`）。下書きの保存は、持っているウィンドウがその欄の分だけ書く（`panelStore` の `setPanelOwnership` と `writeDrafts` の `owns`。持たない欄の分は残っているものをそのまま残す）。メインのウィンドウを読み込み直したら、`holding` で知らせ直してもらい、メインのウィンドウに戻した下書きの写しは捨てる。
  - 戻す: 上の帯の「チャット欄に戻す」（いまのプロジェクトの欄を開いて戻す）と ✕・⌘W（メインプロセスが閉じるのを止めて `onCloseRequested` で知らせ、閉じたまま戻す）。どちらも `returnSideWindow` が欄の状態を `returnSidePanels` で送り、メインのウィンドウがシェルの持ち主になってから（`takeSidePanelsBack`）`docked` を返すのを待って閉じる（3 秒で返らなければ閉じる。先に閉じると、このウィンドウが持つシェルが止まる）。
- パネルのブラウザ・ターミナルのタブの別ウィンドウ（`#/popout/browser?panel=&key=&url=&title=&project=`・`#/popout/terminal?panel=&key=&cwd=&label=&project=&command=&title=&env=`。利用者の依頼）: タブの右クリックの「別ウィンドウで開く」（種類の表の `popout`。チャット欄・下のパネルなど、ブラウザ・ターミナルのタブのある欄ならどこでも）。移すときはタブを後始末なしで閉じる（`closeTab` の `keep`。ターミナルのシェルを止めない）。ブラウザ（`PopoutBrowser`）は webview がウィンドウをまたげないので、いまのページの URL で開き直す（ログインは残り、戻る・進むの履歴は引き継がない。ページを移ったら URL のハッシュも移った先にし、戻すときもいまのページで戻す）。ターミナル（`PopoutTerminal`）は同じシェルにつなぎ直し（過去の出力も続きも出る）、持ち主はこのウィンドウになるので、✕ で閉じるとシェルも止まる（タブを閉じたのと同じ）。⌘ を押しながら押した URL は、元の欄のブラウザのタブで開く（`panelOp` の `openBrowser`）。上の帯の「チャット欄に戻す」「下のパネルに戻す」（戻す先の欄で名前が変わる）で元の欄に開き直す（`dockPopout`。ターミナルはメインのウィンドウがシェルの持ち主になってから `docked` を返し、別ウィンドウはそれを待って閉じる）。
- 埋め込みブラウザ（webview）を置く別ウィンドウ（チャット欄・ブラウザのタブ）だけ `webviewTag` を許す（`src/main/app/popouts.ts`）。AI の kickoff_browser の頼み（タブを開く・表に出す・操作している印）は、メインのウィンドウと別ウィンドウのすべてに送り、そのプロジェクトのチャット欄を出しているウィンドウが答える（`src/main/browser/agentBrowser.ts` と `gatherReplies.ts`。受け口の `useAgentBrowserBridge` は `PopoutApp` にも置く）。
