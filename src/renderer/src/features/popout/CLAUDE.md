# 別ウィンドウ（`features/popout`）

チャットの画面の右の欄のサブエージェント・変更・ファイル・メモと子チャットを、メインのウィンドウの外の別ウィンドウで見る（2 枚目の画面に差分・サブエージェントを置いたまま、1 枚目でチャットを続けるなど）。行き先・開き方・ウィンドウの間の知らせは `app/`（`popout.ts`・`windowBus.ts`・`PopoutApp.tsx`）、メインプロセスのウィンドウは `src/main/app/popouts.ts`。

- 開き方: 右の欄のタブの右クリックの「別ウィンドウで開く」と、中身のいちばん上の見出しの行の右端のボタン（`PopOutTabButton`。サブエージェント・子チャット・メモ・変更・ファイルのどれでも同じ位置。`PanelTabPage` が `TabPageContext` で、そのタブを移す操作を中身に渡す。パネルの外・別ウィンドウの中では出さない。以前はタブの列の左の道具にあった）。開けるタブは種類の表の `popout`（`tabKinds.ts`。サブエージェント・子チャット・メモ・変更・ファイル）で、開いたら右の欄からは閉じる（`panel/tabs/popOutTab.ts`。別ウィンドウへ移す）。Mac のアプリのときだけ（`canPopout`）。
- 行き先は URL のハッシュ `#/popout/<種類>?…`（`app/popout.ts` の `popoutPath` / `parsePopout`。純粋関数でテスト）。同じもの（変更は移るファイルを除いて同じ `popoutKey`）がもう開いていれば、メインプロセスがそのウィンドウを前に出し、変更の移るファイルは知らせ `popoutFocus` で渡す。ウィンドウの位置と大きさは、最後のものから少しずらして開く（アプリを閉じるまで覚える）。
- 画面: `main.tsx` が `#/popout/` なら App の代わりに `PopoutApp`（サーバーとのつながり・回答待ち・プロジェクトの色・会話の文字の大きさだけ。サイドバー・通知・ショートカットを 2 つ動かさない）を描く。中身は右の欄と同じ部品: 変更・ファイルは `PopoutFiles`（`SideChanges` / `SideFileView`）、サブエージェントは `PopoutSubagent`（`useChatDetail` ＋ `useChatView` でチャットの画面と同じ状態と操作を作り、`SubagentScreen` を描く）、子チャット（`#/popout/chat?chat=`）は `PopoutChildChat`（チャットの画面の `ChatView` に、親を見る・親チャットに渡す・右の欄に戻すの帯 `ChildChatBar` を足す。`features/chat/CLAUDE.md` の「子チャット」）、メモ（`#/popout/memo?project=&path=&chat=`。開いたチャット（`chat`。メモのタブからなど、なければ付けない）ごとに別のウィンドウ。見出しの「「チャット名」に添付」と右に戻す先に使う）は `SideMemo`。子チャットとメモは、設定の開き方が別ウィンドウのときに札などから直接開く（右の欄のときは、右の欄のタブから移す）。
- 子チャットのウィンドウの閉じ方（`src/main/app/popouts.ts`）: 最小化は閉じ方を聞かずに閉じる（子チャットは残る）。✕・⌘W はメインプロセスが閉じるのを止めて画面に知らせ（IPC の `windows.onCloseRequested`）、画面が閉じ方を聞いてから `windows.closeSelf` で閉じる（画面の `beforeunload` では止められない。利用者の操作がないページでは Chromium が無視する）。アプリの終了は `app.exit` なので止めない。
- メインのウィンドウとのつながり（`app/windowBus.ts`。同じ出どころなので `BroadcastChannel`。`postToMainWindow` はメインのウィンドウを前にも出す）: 選択部分の「チャットに追加」・右クリックの、足す先のチャットの組・メモの添付はメインのそのチャットのチャット欄に足す（`fillComposer`。メモは `attachments` も。`addToChat`）、「流れで見る」は会話のその場所へ（`reveal`）、「動きで見る」は動きを開いてそのサブエージェントの行を強調する（`showActivity` → `focusActivity`）、「ファイルタブで開く」はメインのファイルタブで開く（`openProjectFile`）、返答の「メモに追加」のあとの「開く」・子チャットを右の欄に開く・子チャットから親へ（親を見る・親チャットに渡す）はメインのウィンドウで（`openMemo` / `openChild` / `childToParent`。App が `app/mainWindowMessages.ts` で受ける）。受け取るのは、チャットの知らせはメインの `ChatView`（`features/chat/pane/windowMessages.ts`。同じチャットを 2 つの欄で開いていても、見えている方に 1 回だけ）、ファイルタブ・メモのタブは App。ほかのサブエージェントの画面・変更・ファイルは、別ウィンドウのまま開く（`usePopoutFileLinks`）。
- 足す先のチャット: 右の欄と同じく、中身の右クリックの、足す先のチャットの名前の組と選んだときの「チャットに追加」で、開いたチャット（子チャットはいちばん上の親）に足せる（`SideScope`。`MainChatContext` と、ウィンドウ全体の `SideSelectionAttach`。`features/chat/CLAUDE.md` の「選択部分をチャットに追加」）。
- 表示の設定（会話の文字の大きさ・差分の表示のしかた・確認済みなど）は localStorage をメインのウィンドウと共有し、どのウィンドウで変えても `storage` の知らせでそろう（`lib/storage.ts`）。
- 右の欄に戻す: どの別ウィンドウにも「右の欄に戻す」（`PopoutDockButton`。上の細い帯 `.popout-bar`（何のウィンドウかの札と一緒に。`PopoutApp`）、子チャットは自分の帯 `ChildChatBar` の `extra`）。押すとメインのウィンドウに知らせ（`dockPopout`）、このウィンドウを閉じる（閉じ方は聞かない。メモの書きかけは `flushMemoDrafts` で残してから閉じるので、右の欄で未保存のまま続く）。メインのウィンドウでは `dockPopout.ts` が開き直す: 子チャット = いちばん上の親の右の欄（`openChildSide`）、サブエージェント = そのチャットの右の欄（チャットの画面が描かれてから `openSubagentSide`。子チャットのサブエージェントなら子チャットを開く）、変更・ファイル = 結びついたチャット（子チャットなら、いちばん上の親）の右の欄、メモ = 開いたチャット（`chat`）の右の欄、なければいま見えているそのプロジェクトのチャットの右の欄（どちらもなければメモのタブ）。
