# パレット（`features/palette`）

キーで開いて探して移る一覧。開くのは App（`app/shortcuts.ts`）。

- ⌘K（`CommandPalette`）: プロジェクト・チャット・メモを名前で探して移る。入力欄の下の「プロジェクト / チャット / メモ / チャット内の文言 / メモ内の文言」で探す対象を選ぶ（複数選べ、1 つは残す。`COMMAND_PALETTE_TARGETS`。未保存ならプロジェクト・チャット・メモ）。メモ（`usePaletteMemos`）はすべてのプロジェクトのメモ（フォルダ・画像などメモでないファイルは除く）を、ファイル名（拡張子まで）とメモのフォルダからのパスで絞り込み、横にフォルダとプロジェクト名を出し、押すとそのプロジェクトのメモのタブで開く。メモを探す対象に入れているときだけ、プロジェクトごとのメモの一覧（`memosStore`）を読む。チャット内の文言は文言の全文検索のパネル（`SearchPanel`）と同じ全文検索（`api.search`）で、入力したときだけ探し、名前で見つかったものの後ろに並べて、押すとその発言へ移る。メモ内の文言（利用者の依頼。初めは対象に入れない）は、すべてのプロジェクトのメモ（.md・.html）の中の行をコアが探し（`api.searchMemos`。大文字・小文字を区別しない。1 つのメモから 5 行・全部で 100 行まで）、見つかった所に印を付けた行の文と、横に「メモの名前:行 · プロジェクト名」を、チャット内の文言の後ろに並べる。押すとそのプロジェクトのメモのタブでメモを開き、その行を選んで真ん中に見せる（`?memo=&line=`。下の `features/memo/CLAUDE.md` の「行へ移る」）。中身の文で探す 2 つは、どちらも入力が止まって 200 ミリ秒たってから探す（`textSearchItems.tsx` の `useDebouncedSearch`。行の形は `messageItem` / `memoTextItem`）。
- ⌘K はダイアログで全体を探す役、⌘F は開いているページの中を探す役（利用者の依頼で分けた。ブラウザと同じ）。⌘F は、ページが置いた検索（`ui/pageFind.ts`。画面全体の `CLAUDE.md` の「ページの ⌘F」）を開き、なければボードの検索欄（チャット名で絞り込む）、それもなければ何もしない（前は ⌘K を開いた）。ピントがチャットの中にあるときは、そのチャットの中の検索（`features/chat/CLAUDE.md`）が先に受け取る。
- チャットの中の文言の全文検索（`SearchPanel`。ボードの検索欄の横のボタンから開く。前は ⌘⇧F だったが、利用者の依頼で ⌘⇧F は VS Code と同じく検索タブ（ファイルの中を探す）にした）: チャットのやり取り（自分の発言と AI の返答）をキーワードで全文検索し、その発言へ移る（`openChat` の `focus`）。探す範囲は ⌘⇧A と同じプロジェクトのピル `.palette-project` で、このチャット → いまのプロジェクト（名前で出し、小さく「このプロジェクト」`.palette-project-note`）→ すべて → ほかのプロジェクト（サイドバーの並び。しまったものは出さない）。入力欄の Tab / Shift+Tab でも順に切り替える（端では反対の端へ）。ボードの検索欄の横のボタンからも開く（`openContentSearch`）。
- ⌘⇧A（`ActiveChatsPalette`。Chrome の「タブを検索」と同じキー）: 作業中・回答待ち・未読のチャットを、すべてのプロジェクトから状態ごとに並べる（⌘K と同じ形。分け方は `bucketChats` / `chatsByState`）。送る前の新しいチャット（下書き。サイドバー・ボードの「下書き」と同じもの）もいちばん上に「下書き」として並べる。名前・プロジェクト名で絞り込め、↑↓・Enter で開く。開いている間もチャットの状態の変化に追いつく。
  - 入力欄の下の `PaletteProjectFilter` で「すべて / プロジェクトごと」に絞り込む（チャットのあるプロジェクトだけを数付きでサイドバーの並びに。入力欄の Tab / Shift+Tab でも順に切り替え `cycleProjectFilter`。⌘⇧A で開くたびに「すべて」から）。
  - プロジェクトごとの入口（利用者の依頼）: サイドバーのプロジェクトのカード・プロジェクト画面の見出しのボタン `ActiveChatsButton`（アイコンは入力欄と同じ `Activity`。状態ごとの数が 0 でも出す）と、プロジェクトの右クリックの「作業中・待ちのチャットを一覧」。どれも `openActiveChats({ projectId })`（`openActiveChats.ts`。App が受け取る）で、そのプロジェクトに絞り込んだところから開く（`initialProject`。Tab で「すべて」にも戻れる。しまった・タグで隠れたプロジェクトなら「すべて」）。
  - 右端の切り替えでアーカイブ済みのプロジェクトのチャットも出す（`ACTIVE_CHATS_SHOW_ARCHIVED_PROJECTS`。初めは隠す。アーカイブ済みのプロジェクトがあるときだけ）。
  - プロジェクトのタグの絞り込みも効かせ、絞り込んでいるときは入力欄の横に `TagFilterNotice`。
