# メモ（`features/memo`）

プロジェクトの画面の「メモ」タブ（URL は `#/projects/:id/memos`。`?memo=` で開くメモ。開いたら URL から外す）と、チャットの発言からの「メモに追加」。メモはプロジェクトの外のフォルダの Markdown か HTML（HTML のメモ。下の「HTML のメモ」。種類は拡張子で決める `@shared/memo/kinds` の `memoKindOf`。DB には入れない）。保存先と API はコアの `memos/`（`src/core/CLAUDE.md`）。

## 保存先

- 設定の「メモ」の親フォルダ（`memos_dir`。null なら既定の `~/Documents/<アプリ名> メモ`。開発版は「Kickoff Dev メモ」で、製品版のメモに触らない）の下に、プロジェクトごとのフォルダ（`memo_folder`。初めてメモを使ったときにプロジェクト名から決めて覚える。名前を変えても同じフォルダ）。プロジェクトの設定の「メモ」で、そのプロジェクトだけ別の場所（`memo_path`）にできる。欄は共通の `MemoFolderField`（空なら既定・「選択…」で Finder から・「既定に戻す」）。
- 一覧は店 `stores/memos.ts` の `memosStore`（プロジェクトごと。知らせ `memos`・プロジェクトの変更・設定の変更で取り直し、Finder・Obsidian などでの変更も、コアがフォルダを見張って出す `memos` ですぐ拾う。見張れなかったときのために、ウィンドウに戻ったとき・30 秒たって使ったときにも取り直す）。操作のあとは知らせを待たずに `invalidate` する。

## メモのタブ（`MemoTab`）

- ファイルタブと同じ形（`.changes`）: 左に一覧（見出し `MemoListHead` に題名「メモ」と新しいメモ（押すと Markdown / HTML を選ぶメニュー）・新しいフォルダ・AI でフォルダを整理・取り直し・フォルダをすべて閉じる・一覧を隠す。一覧が狭くて入らないときだけ（`useOverflowCompact`）題名を隠し、AI で整理・取り直し・すべて閉じるを「…」のメニューにまとめる（題名が「メ…」に切れたため）。下に名前で探す欄）、右に開いたメモ。左の一覧は隠せる（`MEMO_LIST_HIDDEN`。どのプロジェクトでも同じ。隠している間は左端の細い帯 `.memo-list-rail` に「メモの一覧を表示」だけを置き、本文を広げる）。一覧の幅はファイル・検索・変更・履歴タブと共通（`CHANGES_LIST_WIDTH`）。開いているメモ（`memoSelected`）と開いているフォルダ（`memoOpenFolders`）はプロジェクトごとに覚える。
- 木は `MemoTree`（エディタの木と同じ見た目。中身のないフォルダも出す。`memoPaths.ts` の `buildMemoTree`）。行をドラッグしてフォルダへ落とすと動かす（ファイルの行ならそのフォルダへ、一覧の空いている所なら直下へ）。右クリックで新しいメモ・新しい HTML メモ・新しいフォルダ（フォルダと空いている所）・名前を変更・Finder で表示・パスをコピー・ゴミ箱に入れる（確かめてから。Finder のゴミ箱から戻せる）。名前で探すと、合うメモを新しく変えた順に平らに並べる（`filterMemos`）。
- 操作は `useMemoActions`（名前はダイアログで聞き、ファイル名に使えない文字は `@shared/memo/names` の `safeMemoName` でそろえる。書いた名前がそのままファイル名（題名 ＋ 拡張子）になる: 同じフォルダに同じ名前（拡張子まで同じ。大文字・小文字の違いは同じとみなす `pathTaken`）があれば、番号を付けずに「同じ名前があります」と知らせて、書いた名前のまま聞き直す。拡張子が違えば（`a.md` と `a.html`）同じ題名でも作れる。名前の変更も同じ。コアも同じ名前は 409）。名前の変更・移動のあとは、開いているメモ・フォルダのパスを付け替える（`remapPath`）。
- 開いたメモは `MemoView`: 見出しに題名（題名 ＝ ファイル名。書き換えられる欄は拡張子 `.md`・`.html` などを除いた部分で、すぐ後ろに拡張子 `.memo-title-ext` を続けて見せる。名前を変えても同じ拡張子を付け直す `memoTitle` / `renamedPath`。いつでも書き換えられる欄 `.memo-title`（押せばそのままキャレットが入り、入力の画面に切り替えない）で、本文と同じく ⌘S（題名の欄では Enter も）・保存のボタンで、本文を保存してからファイルの名前を変える。書き換えたままなら「未保存（⌘S で保存）」、Esc で元の題名に戻す。ピントを外しても名前は変えない。開いている側は `onRenamed` でパスを付け替える: メモのタブは選んでいるメモ・開いているフォルダ、右の欄はタブを置き換え（`replaceTab`）、別ウィンドウは URL）とフォルダ・保存の様子・保存のボタン（⌘S）・表示の切り替え（`MEMO_VIEW`。Markdown = `preview`（初め。目のアイコン）/ そのまま = `edit`（`</>` のアイコン）。アイコンだけで、名前と説明は乗せたときに出す）・メモのチャットの開閉（吹き出しのアイコン。下の「メモのチャットと AI の整理」）・Finder で表示。
- 編集は `MemoEditor`（CodeMirror 6。開いたときに初めて読み込む。`kind` で Markdown か HTML の言語にする）で、Markdown のメモはどちらの表示でも書ける。Markdown 表示は Obsidian のライブプレビューと同じ: カーソルのある行（ピントがなければどの行も）だけ記号を見せ、ほかの行は見出し・太字・斜体・コード・取り消し線・リンク（文だけ）・引用・コードの塊（``` を隠す）を整え、箇条書きは「•」、タスクはチェックボックス（押すと [ ] / [x] を書き換える）、区切り線は線にする。どこをどう見せるかは純粋関数の `livePreview.ts` の `previewMarks`（@lezer/markdown の GFM の木から。テストあり）、エディタの飾りに直すのは `livePreviewExtension.ts`。ファイルの中身は書いたとおり（見せ方だけ）。そのまま表示は記号もそのまま（同じ幅の文字）。表示を切り替えても、書いたもの・元に戻す履歴はそのまま。行を折り返し、Enter でリスト・引用を続ける。⌘F でエディタの検索の欄（置き換えも。メモのタブでも右の欄でも）。
- 保存は `useMemoDocument`: ⌘S（と保存のボタン）だけで保存し、書いている間は保存しない（「未保存（⌘S で保存）」）。まだ保存していない書きかけは `memoDraft`（プロジェクト:パスごと。書いたものと書き始めたときの指紋）に残し、ほかのタブへ移っても・アプリを閉じても失わない（開き直すと未保存のまま戻す。そのあいだにほかで変わっていれば「ほかで変わりました」）。別のメモへ移る・開いているメモ（の入ったフォルダ）の名前を変える・動かす・ゴミ箱に入れる・右の欄のメモのタブを閉じるときは、`memoGuards.ts` の `confirmLeaveMemo` で「保存 / 保存しない / キャンセル」を聞く（開いているメモが `registerMemoGuard` で様子を知らせる）。題名で名前を変えると、書きかけは新しい名前へ持っていく。保存は開いたときの指紋と比べ、ほかで変わっていれば保存せずに「ほかで変わりました」（読み直す / 書いたもので上書き）。そのメモが変わった知らせ（チャットからの追記・Finder・Obsidian などでの変更）が来たら、書きかけでなければ読み直す。

## HTML のメモ

- 拡張子 `.html`・`.htm` のメモ。「新しいメモ」の HTML（`useMemoActions` の `createMemo(folder, "html")`）で、題名の見出しと `<style>` の入ったひな形 `newHtmlMemo` から作る。メモのチャットに頼めば、AI が HTML と CSS で書く（コアがシステムプロンプトで HTML のメモだと伝える）。
- 表示の切り替え（`MEMO_VIEW` を Markdown のメモと共有）は、`preview` = ページ（`HtmlMemoPage`。描いた見た目で、ここでは書けない）/ `edit` = ソース（`MemoEditor` に HTML の言語と色分け `htmlHighlight`）。ソースの部品はページの間も `hidden` で置き、書いたもの・元に戻す履歴を残す。ページはいま書いてあるもの（`useMemoDocument` の `text()`。保存していない書きかけも）を描き、表示を切り替えた・読み直したときに描き直す（AI が書き換えたときもスクロールの位置は保つ）。
- `HtmlMemoPage` は iframe の srcdoc に中身を入れ、`<base>` をメモの入ったフォルダの、コアのファイルの口（`GET /api/projects/:id/memo/file/…`。`htmlPage.ts` の `memoAssetBase` / `withBaseHref`）へ向けて、相対パスの CSS・画像を読む。sandbox は `allow-same-origin` だけ（中の JavaScript・フォーム・ポップアップは動かさない。外から中の文書に手を付けられる）。画面の CSP をそのまま受け継ぐので、インターネット上の画像・フォントは読まない。iframe は `color-scheme: light`（白い地とそろえる。アプリのダークを受け継ぐと、`color-scheme: light dark` と書いたページが暗い配色を選び、白い地に白い文字になる）。
- ページの中: リンクは中で開かない（`#` はページの中で飛ぶ、外のサイト・メールは `window.open` でブラウザなどへ、メモのフォルダの中へのリンク（相対パス。`<base>` で解決した URL から `htmlPage.ts` の `memoLinkPath` でパスに戻す）は、メモなら同じ場所で開き（`MemoView` の `onOpenMemo`。メモのタブは選ぶメモを変え、右の欄・別ウィンドウは `SideMemo` が書きかけを確かめてから開き直してタブ・URL を付け替える）、フォルダ・メモでないファイル（画像など）は Finder で表示、ないものは「リンク先が見つかりません」と知らせる）。右クリックは選んだ文を渡して本文のメニューを開く（チャットに追加・コピーだけ）。ページの中の押下（`pointerdown`・`mousedown`）は親の画面に届かないので、iframe の要素から伝え直す（開いているメニュー・ポップオーバーが外側のクリックで閉じるように。`useDismiss`）。⌘S で保存。
- 「既存のメモに追記」は Markdown のメモだけ（`recentMemos(…, "markdown")`。HTML の最後に足すとページの外に出るため。コアも 400 にする）。

## メモのチャットと AI の整理

- メモのチャット（`MemoChat`）: 見出しの吹き出しのアイコンで本文の右に開く、メモごとに 1 つのふつうのチャット（Claude Code。メインのチャットと同じ `ChatView` で、モデルの選択・音声入力・返事を書きながら見せる・送信待ち・添付・承認などもそのまま）。チャットは DB の `chats.memo_path` で、サイドバー・ボード・パネルのタブには並べない（`stores/chats.ts` の `selectChats` で除き、`useMemoChatOf` で引く）。まだチャットがなければ、最初の指示の入力欄だけを出し（`MemoChatStart`）、送ると `api.startMemoChat` で作る。中には右の欄を重ねない（`PanelHostContext` を null）。
  - AI はメモのファイルを直接読み書きする（コアがメモのフォルダを読み書きできる場所に足す）。書き換えると、コアのメモの変更の知らせで、書きかけでない本文は読み直す。送る前に書きかけの本文を保存する（`ChatView` の `beforeSend` → `useChatSend`。保存できなければ送らない）。
  - 開閉は `MEMO_CHAT_OPEN`。欄は閉じても描いたまま置き（書きかけの文が残る）、開け閉めはほかの欄と同じ動き `--panel-motion-*` で幅（上下に並べるときは高さ）をスライドさせる。幅は境目のつまみで変え `MEMO_CHAT_WIDTH` に覚える（ダブルクリックで初めの 380px。本文を 280px は残す）。メモの見出しの幅が 720px より狭ければ本文の下。
  - 名前の変更・移動はコアが付け替え、ゴミ箱に入れるとアーカイブする。完了・失敗の通知は名前に「メモ: 」を添え、押すとそのメモをメモのタブで開く（`app/notifications.ts`）。
- 本文の右クリック（`useMemoEditMenu`。`MemoEditor` の `onContextMenu`、HTML のメモのページは `HtmlMemoPage` から選んだ文を渡す）: チャットに追加（選んだ文を引用 `> ` にして、メモのチャットの入力欄の後ろに足し、欄を開く。送るのは自分で。文を選んだだけでは足さない）・切り取り・コピー・貼り付け（切り取り・貼り付けは書ける所だけ）。選んだ範囲はピントが外れても見えるように描く（`drawSelection`）。
- フォルダ（メモのタブの見出しの「AI でフォルダを整理」`MemoPlanDialog`）: 頼み（空ならおまかせ）で `api.aiPlanMemos` が名前の変更・ほかのフォルダへの移動の案（理由つき。使えない案はコアが除く）を返し、チェックの一覧（初めはすべて選ぶ）で見せる。選んだものだけを `useMemoActions` の `moveMany` で 1 件ずつ動かす（開いているメモの書きかけは動かす前に聞き、開いているメモ・フォルダのパスを付け替える。失敗したものは最後にまとめて知らせる）。消す・中身を書き換える案は出ない。

## チャットの「メモに追加」

- 発言の右クリック（`features/chat/messages/useMessageMenu`。チャットの画面の中だけ）に `MemoMenuItems`: 「メモに追加」「AI で要約してメモに追加」「既存のメモに追記 ▸」（最近変えた 12 件）。文は選んでいる文、なければ発言の全体。
- `addToMemo` が `api.memoFromChat` を呼ぶ。新しいメモの名前は「<チャット名> チャットメモ<n>」（`chatMemoName`。同じフォルダの同じチャットのメモの次の番号）、中身は見出しと出どころの行（どのチャットの、いつの文か）と本文。追記は区切り線を挟んで最後に足す。
- 画面は移らない（続けてほかの文もメモできるように）。追加している間と追加したあとは画面の下に `MemoProgress`（App と別ウィンドウに 1 つ）を出し、「開く」でそのメモを開く（下の「チャットから開く」）。

## チャットから開く

- `openMemoFromChat`（`openMemoFrom.ts`）: 設定の「チャットからメモを開く場所」（`MEMO_OPEN_IN`。初めは右の欄）で、右の欄 = そのチャット（子チャットなら、いちばん上の親）の画面の右の欄のメモのタブ（`memo`。`openInRootSide`）/ 別ウィンドウ（`#/popout/memo`）。チャットが分からなければメモのタブ。別ウィンドウの中から右の欄に開くときは、ウィンドウ間の知らせ `openMemo` でメインのウィンドウに頼む。
- 中身は `SideMemo`（メモのタブの右と同じ `MemoView`。⌘S で保存。題名で名前を変えたら、そのパスで開き直す）。メモのタブの一覧で名前を変えた・動かしたメモのタブは、開き直すまで「見つからない」になる。
- 入口: 「メモに追加」のあとの「開く」と、入力欄の上のピル `MemoChip`（最近変えた 12 件 `recentMemos` と「メモのタブで探す・作る」。行はファイル名（拡張子まで）と、その下に入っているフォルダ（直下なら「メモのフォルダの直下」）。プロジェクトにメモがなければ出さない。行の右に「右で開く」「新規ウィンドウで開く」のボタン（設定によらずその場所に。`openMemoFromChat` の `place`）、一覧の上に「行を押したとき」の切り替え（`MEMO_OPEN_IN` をここでも変える。サブエージェントの一覧と同じ `OpenPlaceControls`））。
