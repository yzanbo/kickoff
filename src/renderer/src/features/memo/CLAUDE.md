# メモ（`features/memo`）

プロジェクトの画面の「メモ」タブ（URL は `#/projects/:id/memos`。`?memo=` で開くメモ。開いたら URL から外す）と、チャットの発言からメモを作る・足す項目。メモはプロジェクトの外のフォルダの Markdown か HTML（HTML のメモ。下の「HTML のメモ」。種類は拡張子で決める `@shared/memo/kinds` の `memoKindOf`。DB には入れない）。保存先と API はコアの `memos/`（`src/core/CLAUDE.md`）。

## 保存先

- 設定の「メモ」の親フォルダ（`memos_dir`。null なら既定の `~/Documents/kickoff`。開発版は `kickoff-dev` で、製品版のメモに触らない。この親フォルダの名前だけは空白を入れない。プロジェクトのフォルダ・メモの名前の空白はそのまま）の下に、プロジェクトごとのフォルダ（`memo_folder`。初めてメモを使ったときにプロジェクト名から決めて覚える。名前を変えても同じフォルダ）。プロジェクトの設定の「メモ」で、そのプロジェクトだけ別の場所（`memo_path`）にできる。欄は共通の `MemoFolderField`（空なら既定・「選択…」で Finder から・「既定に戻す」）。
- 一覧は店 `stores/memos.ts` の `memosStore`（プロジェクトごと。知らせ `memos`・プロジェクトの変更・設定の変更で取り直し、Finder・Obsidian などでの変更も、コアがフォルダを見張って出す `memos` ですぐ拾う。見張れなかったときのために、ウィンドウに戻ったとき・30 秒たって使ったときにも取り直す）。操作のあとは知らせを待たずに `invalidate` する。

## メモのタブ（`MemoTab`）

- ファイルタブと同じ形（`.changes`）: 左に一覧（見出し `MemoListHead` に題名「メモ」と新しいメモ（押すと Markdown / HTML を選ぶメニュー）・新しいフォルダ・AI でフォルダを整理・取り直し・フォルダをすべて閉じる・一覧を隠す。一覧が狭くて入らないときだけ（`useOverflowCompact`）題名を隠し、AI で整理・取り直し・すべて閉じるを「…」のメニューにまとめる（題名が「メ…」に切れたため）。下に名前で探す欄）、右に開いたメモ。左の一覧は隠せる（`MEMO_LIST_HIDDEN`。どのプロジェクトでも同じ。隠している間は左端の細い帯 `.memo-list-rail` に「メモの一覧を表示」だけを置き、本文を広げる）。一覧の幅はファイル・検索・変更・履歴タブと共通（`CHANGES_LIST_WIDTH`）。開いているメモ（`memoSelected`）と開いているフォルダ（`memoOpenFolders`）はプロジェクトごとに覚える。
- 木は `MemoTree`（エディタの木と同じ見た目。中身のないフォルダも出す。`memoPaths.ts` の `buildMemoTree`）。フォルダの開閉は高さをなめらかに変える（`ui/Collapse`。入力欄の上の `MemoChipTree` も同じ）。行をドラッグしてフォルダへ落とすと動かす（ドラッグの絵は `markDragSnapshot` で背景を半透明にし、下の落とし先の印が透ける）（ファイルの行ならそのフォルダへ、一覧の空いている所なら直下へ。Finder と同じく、閉じたフォルダに重ねて 700ms 待つと開き、奥のフォルダへも落とせる）。落とす先は、フォルダの行と中身をまとめてアクセントの枠で囲み（中のメモに重ねていても、どのフォルダに入るかが分かるように。直下なら一覧ごと）、運んでいる行は薄くする。落とす先は木の段をまたいで 1 つなので `MemoTab` が持つ（`dropTarget`）。自分自身・自分の中・いまあるフォルダへは落とせず、印も付けない（`canDropInto`）。ドラッグの決まりは `memoDrag.ts`（行は `useMemoRowDrag`、一覧の空いている所は `memoListDropProps`）で、入力欄の上の `MemoChipTree` と共通。動かす前に、動かすものの中で開いているメモ（メモのタブ・右の欄・別ウィンドウのどこでも）の書きかけを聞く（`memoGuards.ts` の `confirmLeaveMemosUnder`）。動かしたあとの選んでいるメモ・開いているフォルダの付け替えは `followMovedMemo`。右クリックで新しいメモ・新しい HTML メモ・新しいフォルダ（フォルダと空いている所）・名前を変更・Finder で表示・パスをコピー・ゴミ箱に入れる（確かめてから。Finder のゴミ箱から戻せる）。名前の変更は、行のダブルクリック・右クリックの「名前を変更」・新しく作ったときに、行の名前の所がそのまま入力欄になる（`MemoTab` の `renaming`。ダイアログは使わない。メモは拡張子を除いた部分を書き、拡張子は欄の右に添えて書き換えさせない。Enter・ピントを外すと決め、Esc でやめる。ふだんの `InlineName` の ✓✕ は行では隠す）。名前で探すと、合うメモを新しく変えた順に平らに並べる（`filterMemos`）。
- 操作は `useMemoActions`。新しいメモ・フォルダは、Finder と同じく名前を聞かずに仮の名前ですぐ作り（「無題のメモ」「名称未設定フォルダ」。同じフォルダにあれば「無題のメモ-2」と番号を付ける `memoPaths.ts` の `untitledPath`）、その行で名前を変える欄を開く（Esc なら仮の名前のまま残る）。名前の変更は `renameTo`: ファイル名に使えない文字は `@shared/memo/names` の `safeMemoName` でそろえ、書いた名前がそのままファイル名（題名 ＋ 拡張子）になる。同じフォルダに同じ名前（拡張子まで同じ。大文字・小文字の違いは同じとみなす `pathTaken`）があれば、番号を付けずに「同じ名前があります」と知らせて、書いた名前のまま欄を開き直す（`MemoRenaming` の `initial` と `round`）。拡張子が違えば（`a.md` と `a.html`）同じ題名でも作れる。コアも同じ名前は 409。HTML のメモの中身がひな形のまま（作ってから書いていない）なら、名前を変えたときに `<title>` と見出しも新しい題名にする。名前の変更・移動のあとは、開いているメモ・フォルダのパスを付け替える（`remapPath`）。
- 開いたメモは `MemoView`: 見出しに題名（題名 ＝ ファイル名。書き換えられる欄は拡張子 `.md`・`.html` などを除いた部分で、すぐ後ろに拡張子 `.memo-title-ext` を続けて見せる。名前を変えても同じ拡張子を付け直す `memoTitle` / `renamedPath`。いつでも書き換えられる欄 `.memo-title`（押せばそのままキャレットが入り、入力の画面に切り替えない）で、本文と同じく ⌘S（題名の欄では Enter も）・保存のボタンで、本文を保存してからファイルの名前を変える。書き換えたままなら「未保存（⌘S で保存）」、Esc で元の題名に戻す。ピントを外しても名前は変えない。右クリックは本文と同じメニュー（`useMemoEditMenu` の `openFor`。切り取り・貼り付けは題名の欄に効き、何も選んでいなければコピーは題名の全体）。開いている側は `onRenamed` でパスを付け替える: メモのタブは選んでいるメモ・開いているフォルダ、右の欄はタブを置き換え（`replaceTab`）、別ウィンドウは URL）とフォルダ・保存の様子・保存のボタン（⌘S）・表示の切り替え（`MEMO_VIEW`。Markdown = `preview`（初め。目のアイコン）/ そのまま = `edit`（`</>` のアイコン）。アイコンだけで、名前と説明は乗せたときに出す）・メモのチャットの開閉（吹き出しのアイコン。下の「メモのチャットと AI の整理」）・Finder で表示。
- 編集は `MemoEditor`（CodeMirror 6。開いたときに初めて読み込む。`kind` で Markdown か HTML の言語にする）で、Markdown のメモはどちらの表示でも書ける。Markdown 表示は Obsidian のライブプレビューと同じ: カーソルのある行（ピントがなければどの行も）だけ記号を見せ、ほかの行は見出し・太字・斜体・コード・取り消し線・リンク（文だけ）・引用・コードの塊（``` を隠す）を整え、箇条書きは「•」、タスクはチェックボックス（押すと [ ] / [x] を書き換える）、区切り線は線にする。どこをどう見せるかは純粋関数の `livePreview.ts` の `previewMarks`（@lezer/markdown の GFM の木から。テストあり）、エディタの飾りに直すのは `livePreviewExtension.ts`。ファイルの中身は書いたとおり（見せ方だけ）。そのまま表示は記号もそのまま（同じ幅の文字）。表示を切り替えても、書いたもの・元に戻す履歴はそのまま。行を折り返し、Enter でリスト・引用を続ける。⌘F でエディタの検索の欄（置き換えも。メモのタブでも右の欄でも）。
- 保存は `useMemoDocument`: ⌘S（と保存のボタン）だけで保存し、書いている間は保存しない（「未保存（⌘S で保存）」）。まだ保存していない書きかけは `memoDraft`（プロジェクト:パスごと。書いたものと書き始めたときの指紋）に残し、ほかのタブへ移っても・アプリを閉じても失わない（開き直すと未保存のまま戻す。そのあいだにほかで変わっていれば「ほかで変わりました」）。別のメモへ移る・開いているメモ（の入ったフォルダ）の名前を変える・動かす・ゴミ箱に入れる・右の欄のメモのタブを閉じるときは、`memoGuards.ts` の `confirmLeaveMemo` で「保存 / 保存しない / キャンセル」を聞く（開いているメモが `registerMemoGuard` で様子を知らせる）。題名で名前を変えると、書きかけは新しい名前へ持っていく。保存は開いたときの指紋と比べ、ほかで変わっていれば保存せずに「ほかで変わりました」（読み直す / 書いたもので上書き）。そのメモが変わった知らせ（チャットからの追記・Finder・Obsidian などでの変更・ほかの場所や別ウィンドウで開いた同じメモの保存）が来たら、書きかけでなければ読み直す（ページ・Markdown の表示もすぐ最新になる。更新のボタンは置かない）。知らせを取りこぼしても古いまま見せないよう、ウィンドウに戻ったとき・サーバーにつなぎ直したときも指紋を確かめる（`checkFresh`）。

## HTML のメモ

- 拡張子 `.html`・`.htm` のメモ。「新しいメモ」の HTML（`useMemoActions` の `createMemo(folder, "html")`）で、題名の見出しと `<style>` の入ったひな形 `newHtmlMemo` から作る。メモのチャットに頼めば、AI が HTML と CSS で書く（コアがシステムプロンプトで HTML のメモだと伝える）。
- 表示の切り替え（`MEMO_VIEW` を Markdown のメモと共有）は、`preview` = ページ（`HtmlMemoPage`。描いた見た目で、ここでは書けない）/ `edit` = ソース（`MemoEditor` に HTML の言語と色分け `htmlHighlight`）。ソースの部品はページの間も `hidden` で置き、書いたもの・元に戻す履歴を残す。ページはいま書いてあるもの（`useMemoDocument` の `text()`。保存していない書きかけも）を描き、表示を切り替えた・読み直したときに描き直す（AI が書き換えたときもスクロールの位置は保つ）。ページが読む CSS・画像などがメモのフォルダで変わったとき（知らせ `memos` のパスがこのメモでない・分からない）も、iframe を読み直す（ファイルの口は no-cache なので変わったものを取り直す）。
- `HtmlMemoPage` は iframe の srcdoc に中身を入れ、`<base>` をメモの入ったフォルダの、コアのファイルの口（`GET /api/projects/:id/memo/file/…`。`htmlPage.ts` の `memoAssetBase` / `withBaseHref`）へ向けて、相対パスの CSS・画像を読む。sandbox は `allow-same-origin` だけ（中の JavaScript・フォーム・ポップアップは動かさない。外から中の文書に手を付けられる）。画面の CSP をそのまま受け継ぐので、インターネット上の画像・フォントは読まない。iframe は `color-scheme: light`（白い地とそろえる。アプリのダークを受け継ぐと、`color-scheme: light dark` と書いたページが暗い配色を選び、白い地に白い文字になる）。
- ページの中: リンクは中で開かない（`#` はページの中で飛ぶ、外のサイト・メールは `window.open` でブラウザなどへ、メモのフォルダの中へのリンク（相対パス。`<base>` で解決した URL から `htmlPage.ts` の `memoLinkPath` でパスに戻す）は、メモなら同じ場所で開き（`MemoView` の `onOpenMemo`。メモのタブは選ぶメモを変え、右の欄・別ウィンドウは `SideMemo` が書きかけを確かめてから開き直してタブ・URL を付け替える）、フォルダ・メモでないファイル（画像など）は Finder で表示、ないものは「リンク先が見つかりません」と知らせる）。右クリックは選んだ文を渡して本文のメニューを開く（チャットに足す項目と、切り取り・貼り付けのないクリップボードの組）。ページの中の押下（`pointerdown`・`mousedown`・`mouseup`）とスクロールは親の画面に届かないので、iframe の要素から伝え直す（開いているメニュー・ポップオーバーが外側のクリックで閉じるように。`useDismiss`。選び終えたら「チャットに追加」を出し、スクロールで消す）。⌘S で保存。
- 「既存のメモに追記」「既存のメモに AI で組み込んで書き直す」は Markdown のメモだけ（`recentMemos(…, "markdown")`。HTML の最後に足すとページの外に出るため。コアも 400 にする）。

## メモのチャットと AI の整理

- メモのチャット（`MemoChat`）: 見出しの吹き出しのアイコンで本文の右（か下）に開く、メモごとに 1 つのふつうのチャット（Claude Code。足す先のチャットと同じ `ChatView` で、モデルの選択・音声入力・返事を書きながら見せる・送信待ち・添付・承認などもそのまま）。チャットは DB の `chats.memo_path` で、サイドバー・ボード・パネルのタブには並べない（`stores/chats.ts` の `selectChats` で除き、`useMemoChatOf` で引く）。まだチャットがなければ、最初の指示の入力欄だけを出し（`MemoChatStart`。会話が始まったあとと同じく定型文の帯とコンテキストのメーター（0%）も出す）、送ると `api.startMemoChat` で作る。中には右の欄を重ねない（`PanelHostContext` を null）。
  - 置き場所は欄の見出しのアイコンの切り替え（下に表示 / 右に表示。`MEMO_CHAT_PLACE`。どのメモでも同じ）で選ぶ。右は幅（`MEMO_CHAT_WIDTH`。左右のつまみ）、下は高さ（`MEMO_CHAT_HEIGHT`。本文と欄を合わせた高さの %。上下のつまみ）を覚える。幅で勝手に下へ回さない（前はメモの幅が 720px 以下なら右でも下に並べたが、下は切り替えで別に選べるので、どちらにするかは利用者が選ぶ。右で狭いときは、欄を 260px より狭くせず本文が縮む）。
  - AI はメモのファイルを直接読み書きする（コアがメモのフォルダを読み書きできる場所に足す）。書き換えると、コアのメモの変更の知らせで、書きかけでない本文は読み直す。送る前に書きかけの本文を保存する（`ChatView` の `beforeSend` → `useChatSend`。保存できなければ送らない）。
  - 開閉は `MEMO_CHAT_OPEN`。欄は閉じても描いたまま置き（書きかけの文が残る）、開け閉めはほかの欄と同じ動き `--panel-motion-*` で幅（上下に並べるときは高さ）をスライドさせる。下に置いたときは、入力欄を下に止めたまま上の会話の部分だけを伸び縮みさせる（`useBottomChatMotion`。開くときはメモの下の入力欄をすぐ隠して、欄をその入力欄の高さ `--memo-quick-h` から伸ばし、閉じるときはその高さまで縮めてから入れ替える。動いている間は欄の中身を開き終えたときの高さのまま下にそろえ、上を切る。前は欄が 0 から伸び、メモの下の入力欄も同時に畳んだので、入力欄ごと上下に動いて見えた）。幅は境目のつまみで変え `MEMO_CHAT_WIDTH` に覚える（ダブルクリックで初めの 380px。本文を 280px は残す）。
  - メモのチャットの欄を閉じている間は、メモ（ページ・本文）の下に、そのメモを AI に直してもらう入力欄 `MemoQuickChat` をいつも出す（メモのタブ・右の欄・別ウィンドウのどれでも。どれも `MemoView`）。欄を開いても描いたまま置き、欄の開け閉めと同じ動きで高さを畳む・戻す（`.memo-quick-slot`。すぐ消すと、欄が開ききるまでの間、入力欄のあった所が空いて見えた）。入力欄はチャット欄と同じ `Composer`（定型文の帯 `SnippetBar`・添付・ほかのチャットの参照・音声入力・モデルなどの選択・メーター `ContextMeter`・送信と ▾ の「質問として送る」・作業中の いま / あとで の切り替え `QueueModeToggle`・中断）。送る先はメモのチャットで、送り方はチャットの画面と同じ `useChatSend`（送信待ち・圧縮中の様子は読まない）。まだチャットがなければ、送ると `api.startMemoChat` で作って `addChat`（作業中にならないので、切り替えも ▾ も出さない。選択はできたチャットのものから始め直す）。送る前に書きかけの本文を保存する（`beforeSend`）。会話は出さず、上に左端の名前「メモのチャット」（欄の見出しと同じ吹き出しのアイコン・色・太さ。本文の右クリックの「メモのチャット」の組や選んだときの「メモのチャットに追加」の行き先がこの入力欄だと分かるように。前は名前がなく、ほかのチャットの入力欄と見分けられなかった）・作業中・回答待ち・エラー・終わった（未読）の様子（`StatusSlot`）・右端にいつも「会話を開く」（欄を開く）の 1 行だけ。書きかけの文はメモのチャットの入力欄と同じ `chatDraft` を使う（欄を開くと続きを書ける）。
  - 名前の変更・移動はコアが付け替え、ゴミ箱に入れるとアーカイブする。完了・失敗の通知は名前に「メモ: 」を添え、押すとそのメモをメモのタブで開く（`app/notifications.ts`）。
- 右の欄・別ウィンドウのメモのチャットの中は、ほかの右の欄のタブと同じく足す先のチャットと「メモのチャット」の両方に足せる（選んだときのボタン・発言の右クリック。`features/chat/CLAUDE.md` の「選択部分をチャットに追加」）。
- 本文の右クリック（`useMemoEditMenu`。`MemoEditor` の `onContextMenu`、HTML のメモのページは `HtmlMemoPage` から選んだ文を渡す。見出しの題名の欄も同じメニュー）: 足す先ごとに見出し（`.menu-label`）を付けて組に分ける（上が足す先のチャット（見出しはチャットの名前。チャットの右の欄・別ウィンドウで開いたときだけ）、下が「メモのチャット」）。それぞれ「選択部分を追加」（選んでいなければ「メモを添付」。メモ全体の添付は書きかけを先に保存する）と「パスを追加」（メモのファイルのフルパスを足す）。足す先の口は `memoChatTargets.ts`（メモのチャットに足すときは欄を開く。`MemoChatHandle.add(text, attachments?)`）。送るのは自分で。文を選んだだけでは足さない（選ぶと上に足す先のボタンが出る。下の「「チャット名」に添付」）。その下に見出し「クリップボード」の組（共有の `ClipboardItems`）: 切り取り・コピー・パスを含めてコピー（選択部分の前にメモのファイルのフルパスと行番号 `…/DB.md:12-14` を付ける。`@/lib/pathCopy` の `textWithPath`）・パスをコピー・貼り付け（切り取り・貼り付けは書ける所だけ）。選んだ範囲はピントが外れても見えるように描く（`drawSelection`）。
- フォルダ（メモのタブの見出しの「AI でフォルダを整理」`MemoPlanDialog`）: 頼み（空ならおまかせ）で `api.aiPlanMemos` が名前の変更・ほかのフォルダへの移動の案（理由つき。使えない案はコアが除く）を返し、チェックの一覧（初めはすべて選ぶ）で見せる。選んだものだけを `useMemoActions` の `moveMany` で 1 件ずつ動かす（開いているメモの書きかけは動かす前に聞き、開いているメモ・フォルダのパスを付け替える。失敗したものは最後にまとめて知らせる）。消す・中身を書き換える案は出ない。

## チャットの文をメモにする

- 発言の右クリック（`features/chat/messages/useMessageMenu`。チャットの画面の中だけ）に `MemoMenuItems`。新しく作るのか・既存のメモに足すのかを見出しで分ける（前の「メモに追加」は、どちらか分かりにくかった）: 見出し「新しいメモ」の下に「そのままメモにする」「AI で要約してメモにする」、見出し「既存のメモ」の下に「追記する ▸」「AI で組み込んで書き直す ▸」（▸ は最近変えた 12 件。前の「既存のメモと AI でまとめる」は、何が起きるか分かりにくかった）。文は選んでいる部分（返答は Markdown に戻したもの）、なければ発言の全体。4 つの項目は `MemoModeItems`（▸ の一覧は `RecentMemoItems`）。
- チャットの流れの返答で文を選ぶと、上の足す先のボタン（「チャットに追加」「新しい子チャットで聞く」「新しいチャットで聞く」）の横に「メモ ▾」（`SelectionMemoButton`。選択部分を Markdown に戻したもの）。押してもすぐにはメモにせず、下に右クリックと同じ見出し付きの 4 項目（`MemoModeItems`）を開く（前は「メモ」で既定の入れ方ですぐメモにし、▾ でほかの入れ方と既定を選んだが、何が起きるか押す前に分からなかった。既定の設定はなくした）。右の欄・別ウィンドウの子チャット・サブエージェントの会話で選んだときも出す（出どころは子チャットならその子、サブエージェントなら足す先のチャット）。メモのチャットの中・メモの本文で選んだときは出さない。
- `addToMemo`（入れ方 `MemoAddMode`: `new` / `summarize` / `append` / `merge`）が `api.memoFromChat` を呼ぶ。新しいメモの名前は「<チャット名> チャットメモ<n>」（`chatMemoName`。同じフォルダの同じチャットのメモの次の番号）、中身は見出しと出どころの行（どのチャットの、いつの文か）と本文。追記は区切り線を挟んで最後に足す。AI で組み込むは、コアの AI がメモの中身に文を組み込んで 1 つのメモに書き直し、メモのファイルをそのまま書き換える（確かめは挟まない。開いているメモは、書きかけでなければ読み直す）。
- 画面は移らない（続けてほかの文もメモできるように）。追加している間と追加したあとは画面の下に `MemoProgress`（App と別ウィンドウに 1 つ）を出し、「開く」でそのメモを開く（下の「チャットから開く」）。

## チャットから開く

- `openMemoFromChat`（`openMemoFrom.ts`）: 設定の「チャットからメモを開く場所」（`MEMO_OPEN_IN`。初めは右の欄）で、右の欄 = そのチャット（子チャットなら、いちばん上の親）の画面の右の欄のメモのタブ（`memo`。`openInRootSide`）/ 別ウィンドウ（`#/popout/memo`）。チャットが分からなければメモのタブ。別ウィンドウの中から右の欄に開くときは、ウィンドウ間の知らせ `openMemo` でメインのウィンドウに頼む。
- 中身は `SideMemo`（メモのタブの右と同じ `MemoView`。⌘S で保存。題名で名前を変えたら、そのパスで開き直す）。メモのタブの一覧で名前を変えた・動かしたメモのタブは、開き直すまで「見つからない」になる。
- 入口: チャットの文でメモを作った・足したあとの「開く」と、入力欄の上のピル `MemoChip`（メモのフォルダの木 `MemoChipTree` と、いちばん下の「メモのタブを開く」（探す・作るのはメモのタブで）。行をドラッグしてフォルダ（空いている所なら直下）へ動かせる（メモのタブの木と同じ決まり。出しているのはメモの入ったフォルダだけなので、空のフォルダへはメモのタブから）。木はメモのタブと同じ並びで、メモのファイルだけ（メモの入っていないフォルダは出さない。`memoPaths.ts` の `buildMemoFileTree`）。フォルダの行は押すと開閉し（`Collapse` で高さをなめらかに。一覧は入力欄の上に開くので、伸び縮みに合わせて吹き出しの位置も動く）、開いているフォルダはメモのタブと同じ `memoOpenFolders` を使う（どちらで開け閉めしても、もう一方も同じになる）。プロジェクトにメモがなければ出さない。メモの行の右に「右で開く」「新規ウィンドウで開く」のボタン（設定によらずその場所に。`openMemoFromChat` の `place`）、一覧の上に「行を押したとき」の切り替え（`MEMO_OPEN_IN` をここでも変える。サブエージェントの一覧と同じ `OpenPlaceControls`））。メモの行の右の先頭に「このチャットに添付」（下の「「チャット名」に添付」）。送る前のチャット（新しいチャット・新しい子チャット）の入力欄の上にも出し（`chatId` が null）、「このチャットに添付」はその入力欄に足す（`onAttach`）。

## 開いたチャットに添付

メモを、開いたチャット（メインエージェント）の入力欄に添付して、AI に読ませ・続きを書かせる（メモのチャットとは別。メモのチャットはメモの横で話す欄、こちらはいま作業しているチャットにメモを渡す）。

- 入口: 右の欄・別ウィンドウのメモの見出しのクリップのボタン（`MemoView` の `attachTo`。`SideMemo` の `chatId`。メモのタブでは出さない）・本文で文を選ぶと上に出る足す先のボタン（`MemoSelectionAttach`。足す先は右クリックと同じ `memoChatTargets` で、右の欄・別ウィンドウでは「「機能開発」に追加」と「メモのチャットに追加」の 2 つ（子チャットの中で選んだときと同じ形）、メモのタブでは「メモのチャットに追加」だけ（メモのチャットに足すときは欄を開く。`MemoChatTarget.addQuote`）。AI の返答で選んだときと同じ部品 `SelectionAttachBox` で、押すとすぐ選択部分の引用を足す。本文は編集の部品の `selectionRect`（ピントがあるときだけ）、HTML のページは `HtmlMemoPage` の `handleRef` の `selected`（ページにピントがあるときだけ。ページの中の mouseup・スクロールは親へ伝え直す））・本文の右クリックの、足す先のチャットの名前の組（「メモを添付」「選択部分を追加」「パスを追加」）・入力欄の上のピル `MemoChip` の行の「このチャットに添付」。
- 文を選んでいなければメモそのものを添付する: `memoAttachment.ts` の `memoAttachment(path)`（`Attachment` の `memo` にメモのフォルダからの相対パス。アップロードしない）を入力欄の添付に足す（同じメモは重ねない `useComposerFiles` の `addAttachments`）。チップは付箋のアイコンとパスと「メモ」（`AttachmentChip` の `MemoAttachmentChip`。送ったあとは押すとそのメモを開く `openMemoFromChat`）。書きかけの本文は先に保存し、保存できなければ添付しない。送ると、コアがメモのファイルの絶対パスを指示に書き添え、AI が Read で読み・頼めば直接書き換える（`src/core/CLAUDE.md` の「メモ」）。
- 文を選んでいれば、引用にして入力欄の後ろに足す（`memoQuote`: 「メモ「場所」から:」と `> ` の引用。場所は `@/lib/pathCopy` の `lineLocation` のファイルのフルパスと行番号 `…/設計/DB.md:12-14`。AI がファイルを開いて前後も読めるように。行は本文の編集の部品の `selectedLines`。HTML のページ・題名の欄で選んだときは行が分からないのでパスだけ）。
- 足すのは `attachMemo.ts` の `attachMemoToChat(chatId, path, text?)`（text がなければメモ全体の添付）: チャットに足す共通の口 `addToChat`（そのチャットの画面の `fillComposer`（`append`・`attachments`）。別ウィンドウの中からは、ウィンドウ間の知らせ `fillComposer`（`attachments` 付き）でメインのウィンドウのそのチャットに頼む）。チャットの画面が開いていなければ知らせる。送るのは自分で。
