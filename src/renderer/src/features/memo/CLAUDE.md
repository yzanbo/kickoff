# メモ（`features/memo`）

プロジェクトの画面の「メモ」タブ（URL は `#/projects/:id/memos`。`?memo=` で開くメモ。開いたら URL から外す）と、チャットの発言からの「メモに追加」。メモはプロジェクトの外のフォルダの Markdown（DB には入れない）。保存先と API はコアの `memos/`（`src/core/CLAUDE.md`）。

## 保存先

- 設定の「メモ」の親フォルダ（`memos_dir`。null なら既定の `~/Documents/<アプリ名> メモ`。開発版は「Kickoff Dev メモ」で、製品版のメモに触らない）の下に、プロジェクトごとのフォルダ（`memo_folder`。初めてメモを使ったときにプロジェクト名から決めて覚える。名前を変えても同じフォルダ）。プロジェクトの設定の「メモ」で、そのプロジェクトだけ別の場所（`memo_path`）にできる。欄は共通の `MemoFolderField`（空なら既定・「選択…」で Finder から・「既定に戻す」）。
- 一覧は店 `stores/memos.ts` の `memosStore`（プロジェクトごと。知らせ `memos`・プロジェクトの変更・設定の変更で取り直し、Finder などでの変更はウィンドウに戻ったとき・30 秒たって使ったときに拾う）。操作のあとは知らせを待たずに `invalidate` する。

## メモのタブ（`MemoTab`）

- ファイルタブと同じ形（`.changes`）: 左に一覧（見出しに新しいメモ・新しいフォルダ・取り直し・フォルダをすべて閉じる、下に名前で探す欄）、右に開いたメモ。一覧の幅はファイル・検索・変更・履歴タブと共通（`CHANGES_LIST_WIDTH`）。開いているメモ（`memoSelected`）と開いているフォルダ（`memoOpenFolders`）はプロジェクトごとに覚える。
- 木は `MemoTree`（エディタの木と同じ見た目。中身のないフォルダも出す。`memoPaths.ts` の `buildMemoTree`）。行をドラッグしてフォルダへ落とすと動かす（ファイルの行ならそのフォルダへ、一覧の空いている所なら直下へ）。右クリックで新しいメモ・新しいフォルダ（フォルダと空いている所）・名前を変更・Finder で表示・パスをコピー・ゴミ箱に入れる（確かめてから。Finder のゴミ箱から戻せる）。名前で探すと、合うメモを新しく変えた順に平らに並べる（`filterMemos`）。
- 操作は `useMemoActions`（名前はダイアログで聞き、ファイル名に使えない文字は `@shared/memo/names` の `safeMemoName` でそろえ、同じフォルダの名前と重なれば番号を付ける）。名前の変更・移動のあとは、開いているメモ・フォルダのパスを付け替える（`remapPath`）。
- 開いたメモは `MemoView`: 見出しに題名（`.md` を除く。いつでも書き換えられる欄 `.memo-title`（押せばそのままキャレットが入り、入力の画面に切り替えない）で、本文と同じく ⌘S（題名の欄では Enter も）・保存のボタンで、本文を保存してからファイルの名前を変える。書き換えたままなら「未保存（⌘S で保存）」、Esc で元の題名に戻す。ピントを外しても名前は変えない。開いている側は `onRenamed` でパスを付け替える: メモのタブは選んでいるメモ・開いているフォルダ、右の欄はタブを置き換え（`replaceTab`）、別ウィンドウは URL）とフォルダ・保存の様子・保存のボタン（⌘S）・表示の切り替え（`MEMO_VIEW`。Markdown = `preview`（初め。目のアイコン）/ そのまま = `edit`（`</>` のアイコン）。アイコンだけで、名前と説明は乗せたときに出す）・Finder で表示。
- 編集は `MarkdownEditor`（CodeMirror 6。開いたときに初めて読み込む）で、どちらの表示でも書ける。Markdown 表示は Obsidian のライブプレビューと同じ: カーソルのある行（ピントがなければどの行も）だけ記号を見せ、ほかの行は見出し・太字・斜体・コード・取り消し線・リンク（文だけ）・引用・コードの塊（``` を隠す）を整え、箇条書きは「•」、タスクはチェックボックス（押すと [ ] / [x] を書き換える）、区切り線は線にする。どこをどう見せるかは純粋関数の `livePreview.ts` の `previewMarks`（@lezer/markdown の GFM の木から。テストあり）、エディタの飾りに直すのは `livePreviewExtension.ts`。ファイルの中身は書いたとおり（見せ方だけ）。そのまま表示は記号もそのまま（同じ幅の文字）。表示を切り替えても、書いたもの・元に戻す履歴はそのまま。行を折り返し、Enter でリスト・引用を続ける。⌘F でエディタの検索の欄（置き換えも。メモのタブでも右の欄でも）。
- 保存は `useMemoDocument`: ⌘S（と保存のボタン）だけで保存し、書いている間は保存しない（「未保存（⌘S で保存）」）。まだ保存していない書きかけは `memoDraft`（プロジェクト:パスごと。書いたものと書き始めたときの指紋）に残し、ほかのタブへ移っても・アプリを閉じても失わない（開き直すと未保存のまま戻す。そのあいだにほかで変わっていれば「ほかで変わりました」）。別のメモへ移る・開いているメモ（の入ったフォルダ）の名前を変える・動かす・ゴミ箱に入れる・右の欄のメモのタブを閉じるときは、`memoGuards.ts` の `confirmLeaveMemo` で「保存 / 保存しない / キャンセル」を聞く（開いているメモが `registerMemoGuard` で様子を知らせる）。題名で名前を変えると、書きかけは新しい名前へ持っていく。保存は開いたときの指紋と比べ、ほかで変わっていれば保存せずに「ほかで変わりました」（読み直す / 書いたもので上書き）。Kickoff の中でそのメモが変わった知らせ（チャットからの追記など）が来たら、書きかけでなければ読み直す。

## チャットの「メモに追加」

- 発言の右クリック（`features/chat/messages/useMessageMenu`。チャットの画面の中だけ）に `MemoMenuItems`: 「メモに追加」「AI で要約してメモに追加」「既存のメモに追記 ▸」（最近変えた 12 件）。文は選んでいる文、なければ発言の全体。
- `addToMemo` が `api.memoFromChat` を呼ぶ。新しいメモの名前は「<チャット名> チャットメモ<n>」（`chatMemoName`。同じフォルダの同じチャットのメモの次の番号）、中身は見出しと出どころの行（どのチャットの、いつの文か）と本文。追記は区切り線を挟んで最後に足す。
- 画面は移らない（続けてほかの文もメモできるように）。追加している間と追加したあとは画面の下に `MemoProgress`（App と別ウィンドウに 1 つ）を出し、「開く」でそのメモを開く（下の「チャットから開く」）。

## チャットから開く

- `openMemoFromChat`（`openMemoFrom.ts`）: 設定の「チャットからメモを開く場所」（`MEMO_OPEN_IN`。初めは右の欄）で、右の欄 = そのチャット（子チャットなら、いちばん上の親）の画面の右の欄のメモのタブ（`memo`。`openInRootSide`）/ 別ウィンドウ（`#/popout/memo`）。チャットが分からなければメモのタブ。別ウィンドウの中から右の欄に開くときは、ウィンドウ間の知らせ `openMemo` でメインのウィンドウに頼む。
- 中身は `SideMemo`（メモのタブの右と同じ `MemoView`。⌘S で保存。題名で名前を変えたら、そのパスで開き直す）。メモのタブの一覧で名前を変えた・動かしたメモのタブは、開き直すまで「見つからない」になる。
- 入口: 「メモに追加」のあとの「開く」と、入力欄の上のピル `MemoChip`（最近変えた 12 件 `recentMemos` と「メモのタブで探す・作る」。プロジェクトにメモがなければ出さない。行の右に「右で開く」「新規ウィンドウで開く」のボタン（設定によらずその場所に。`openMemoFromChat` の `place`）、一覧の上に「行を押したとき」の切り替え（`MEMO_OPEN_IN` をここでも変える。サブエージェントの一覧と同じ `OpenPlaceControls`））。
