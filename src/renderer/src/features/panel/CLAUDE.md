# タブの入れ物（`features/panel`）

チャット・新しいチャット・ブラウザ・ターミナル・サブエージェント・変更・ファイル・メモのタブを並べる欄。6 つの欄（ボードの右のパネル・画面の右端のチャット欄・下のパネル（フッター）・チャットの画面の右の欄（サブエージェントの画面・変更・ファイル）・プロジェクトの「メモ」タブの右（開いたメモ。`features/memo/CLAUDE.md` の「右のタブ」）・プロジェクトの「ファイル」「検索」「変更」タブの右（開いたファイル。`features/editor/CLAUDE.md` の「右のファイルのタブ」））は同じ `Panel` / `usePanel` で、違いは `surfaces.ts` の `SURFACES` と、欄の殻が渡す `frame` だけ。サブエージェントのタブは右の欄（チャットのタブの中に入れ子にしたパネル）だけに開く（ボード・チャット欄・フッターのタブにはしない。メインエージェントとのつながりのまま見るため。サブエージェントの見せ方は `features/chat/CLAUDE.md`）。タブの中身のうちチャットは `features/chat/CLAUDE.md`、ターミナル・ブラウザ・▾ のメニューは `features/terminal/CLAUDE.md`。

## 欄の決まり（`SURFACES`）

欄ごとの違いは作る側・描く側で分岐させず `SURFACES` に集める（覚える名前の頭 `memoryPrefix`・初めに見せるタブの種類 `defaultKinds`・Esc で閉じるか・最後のタブを閉じたら欄も閉じるか・タブがないまま開いたときに始めるもの・開閉を覚える設定・閉じるボタン（タブの列の左の道具の先頭か最後か、右上のペインのタブの列の右端 `right`）・分けるボタンを置かないか `noSplitButtons`・大きくする切り替えとその名前 `maximizeLabels`・タブがないときの案内・出す種類が決まっているか `fixedKinds`・新しい子チャットを開けるか `newChild`・タブの種類の札を付けないか `noKindBadges`・クラス・根のクラス `rootClass`）。メモのタブの右（`memos`）は、メモのタブ（種類は「ファイル」に入る）だけを並べ（`fixedKinds`）、Esc でも最後のタブを閉じても閉じず、種類の札「メモ」を付けない。根は `.board-panel.memo-panel`（`styles/editor/memo-panel.css` で、チャットタブと同じく開閉の動きを使わず右いっぱいに）。ファイル・検索・変更のタブの右（`files`）も同じ決まりで、ファイルのタブ（`projectFile`）だけを並べ、根は `.board-panel.file-panel`（同じ CSS のファイル）。

## 状態（`state/`）

- 1 つの欄の状態（`PanelState`: タブ・分割の配置・開いているか・サイドバーとの連動の覚え）は店（`panelStore.ts`）が欄・画面ごとに覚え、変えるのはすべて純粋関数の `panelReducer`（閉じたタブの後始末・保存は店）。部品は `usePanelState` で読み、`dispatchPanel` で変える（画面に出ていない欄も、サイドバーの下書きなどから同じ方法で変えられる）。操作は `panelActions(key)`（部品の外からも使え、`usePanel` が束ねる）。タブやプロジェクトを切り替えて戻っても元どおり。覚えるのはアプリを閉じるまで（チャット欄の開閉だけはプロジェクトごとに `projectChatOpen`）。
- `usePanel` が返すもの: `open(chat, focus?)` / `openNew(target, seed?)` / `startNewChat`（欄が決めた作成先 `newChat` で新しいチャットを始める。作成先がない = プロジェクトがないときは、チャットはプロジェクトの中で始めることの案内 `openNoProjectsGuide`。`features/project/CLAUDE.md`）/ `openBrowser` / `openTerminal`（自分で開くタブはピントのあるペインに足し、すでにあればそのペインで表示。欄も開く。隠している種類のタブなら、その種類を出す）・`closeTab(key, { dismiss })`・`isShowingTab` / `isShowing(chatId)`（どれかのペインで表示中か）・`shownTabOf(pane)`・`chatOf(tab)`（タブのチャット。サイドバーの一覧にあれば最新、なければタブの中のチャットから届いたもの）・ペインの操作（`splitPane` / `moveTab` / `closePane` / `returnToHome` / `focusPane` / `resizeSplit` / `equalizeSplit`）など。
- 配置を変える操作は、いまのタブにそろえた配置から変える（自動で足したタブがまだ配置に入っていないまま変えると、そのタブを移す・分ける操作が何もしなかった）。
- タブの中身は `PanelTabPage`（種類ごとの中身は `PAGES`）。表示していないタブも hidden で残し、入力中の文・スクロール位置を保つ。チャットのタブはサイドバーと連動して自動で増えるので、中身は初めて表示したときに作る（`TabKindSpec.lazy` と `Panel` の `mountedTabs`）。

## タブの種類（`tabs/tabKinds.ts`）

種類（`chat` / `new` / `browser` / `terminal` / `subagent` / `changes` / `file` / `memo` / `child` / `newChild` / `projectView` / `projectFile`（プロジェクトのファイル・検索・変更のタブの右のファイル。キー・開き方は `features/editor/fileTabs.ts`、開くのは `panelActions(key).openPanelTab`）。変更（作業場所ごとに 1 つ。`changesTab`）・ファイル（作業場所のファイルごとに 1 つ。`fileTab`）・メモ（メモごとに 1 つ。`memoTab`。右の欄では開いたチャット `chatId`、メモのタブの右ではチャットなし（null））・子チャット（子チャットごとに 1 つ。`childTab`。孫・ひ孫もいちばん上の親の欄に）・新しい子チャット（押すたびに新しいキー。`newChildTab`）・プロジェクトの画面（ファイル・検索・履歴ごとに 1 つ。`projectViewTab`。中身は `tabs/SideProjectView` で、プロジェクトの左の列の同じタブの画面 `EditorTab` / `HistoryTab` をそのまま描く。作業場所は開いたチャットの作業場所から始め、中の作業場所の切り替えはそのタブの中だけ。別ウィンドウには移せない）はサブエージェントと同じく右の欄だけで、開くのは `panelActions(key).openChanges` / `openFile` / `openMemo` / `openChild` / `openNewChild` / `openProjectView`（開いていれば、移るファイル・目立たせる行だけを変える）。メモと子チャットの開き方は `features/memo/CLAUDE.md`・`features/chat/CLAUDE.md`。この 5 つは別ウィンドウへ移せる（種類の表の `popout`。タブの右クリックの「別ウィンドウで開く」と、中身のいちばん上の見出しの行の右端のボタン（`PopOutTabButton`。サブエージェント・子チャット・メモ・変更・ファイルのどれでも同じ位置。`PanelTabPage` が `TabPageContext` で、そのタブを移す操作を中身に渡す。パネルの外・別ウィンドウの中では出さない。以前はタブの列の左の道具にあった）。`tabs/popOutTab.ts`。`features/popout/CLAUDE.md`）。型は `panelTypes.ts` の `PanelTab`）ごとの違い（キーの決め方・「表示するタブ」のどれに入るか `shows`・アイコンと名前・どのプロジェクトのものか・どのチャットのものか（そのチャットを消したら閉じる）・中身を作る時・閉じたときの後始末（ターミナルはシェルも止める）・どのまとまりに入るか）は、種類で分岐させずに `TAB_KINDS` から引く。チャットのタブのキーは `chatKey(id)`（同じチャットは 1 つのタブ）、サブエージェントのタブは `agentTabKey(行のキー)`（その欄に 1 つ）、ほかは押すたびに新しいキー（`newTabKey`。ターミナルのキーは裏のシェルのキーにも使うので乱数を添える）。

- 右の欄の新しい子チャット（`SURFACES.agents.newChild`）: タブの列の新しいタブのボタンの位置に「新しい子チャット」のボタン（空の欄のボタンと同じアイコン。押すとすぐ開く）と、横の ▾（`agents/AgentPanelAdds`。2 つを 1 つのボタンに見せる `.panel-split-button`。利用者の依頼）で、ほかに右の欄に開けるものを選ぶメニュー: 新しい子チャット ｜ 子チャット ▸（このチャットの子。アーカイブ済みは除く。`openChildChat` の `side`）・サブエージェント ▸（入れ子は親のすぐ下に字下げ。アーカイブしたものは除く。`openSubagentSide`）｜ ファイル・検索・変更・履歴（プロジェクトの左の列のコードのタブと同じ並び。このチャットの作業場所。変更は `openChanges`、ほかは `openProjectView`）｜ メモ ▸（最近変えた 12 件。`features/memo` の `RecentMemoItems`。`openMemo`）。どれも設定の開き方によらずこの右の欄に開き、▸ の一覧が空なら押せない（理由は乗せたときの説明）、空の欄には案内の下に「新しい子チャット」のボタン（`PanelEmpty` の `onNewChild`）。どちらも `agents/useNewChild.ts` が欄のチャット（覚える名前の `scope`）を引き、メモのチャット・アーカイブ済み・分からないチャットでは出さない（チャット欄の「新規の子チャットに送る」と同じ）。空の欄の案内の「「＋」で新しい子チャットを始められます。」も、出すときだけ足す（`SURFACES` の `newChildHint` と `emptyHintOf`。ボタンがないのに案内だけが「＋」を指していた）。押すと入力欄だけのタブ `newChild` を開き、中身は `features/chat/children/NewChildPane`（最初の文を送ると子チャットを作り、そのタブを `childTab` に置き換える。新しいチャットのタブと同じ流れ。`features/chat/CLAUDE.md` の「子チャット」）。札は「子」で、色も子チャットと同じ。
- 種類の札（`TabKindSpec.badge`）: チャットの画面の右の欄に並ぶメモ・サブエージェント・子チャットのタブは、名前の前に「メモ」「サブ」「子」の札を付け、表示中のハイライトも同じ形にして、色だけ種類ごとに変える（メモ = 琥珀・サブ = 紫・子 = 青。`PanelTab` の `badge` → `.panel-tab-typed.tab-kind-<種類>`、`styles/panel/side-panel-tab-kinds.css`）。札の文をタブごとに変えるときは `TabKindSpec.BadgeText` の部品（子チャットは深さで「子 / 孫 / ひ孫」と、深さの色 `--child-depth-<n>`。`features/chat/CLAUDE.md` の「子チャット」）。タブを見ただけで種類が分かるように。子チャットの名前の頭の「↳」は札に置き換えた（サブエージェントの入れ子の「↳」と見分けにくかったため）。

- チャット・子チャット・サブエージェントのタブは吹き出しの代わりに状態の印 `StatusSlot`（サイドバーの行と同じ。作業中で未読があればリングに緑の点）を出し、未読・失敗は名前を太字（`.panel-tab.unread`）。状態はどの種類も `useTabAgentState`（チャット = `panel.chatOf`・子チャット = `useKnownChat`・サブエージェント = チャットの画面の `useSubagentsView`）で決める（以前は子チャットのタブが `tabChat` で引けず、未読・失敗でも太字にならなかった）。名前のダブルクリックでタブの中で名前を変える（`PanelTab` の `onRename` / `editor`。`tabs/useTabRename.ts`）。チャットの見出しには名前を出さない。

## サイドバーとの連動（`state/linkedTabs.ts`）

- パネルのチャットのタブは、サイドバーに出ているチャット（`useLinkedChats`。チャットの店から読み、全プロジェクトはしまったプロジェクトとタグの絞り込みに合わないものを除く。アーカイブ済みは `SIDEBAR_SHOW_ARCHIVED` のときだけ）に、一覧が届いてから `syncLinkedTabs` でそろえる: 一覧にあってタブのないチャットは足し、一覧から外れたチャット（アーカイブして隠した・移した・消した）のタブは閉じる。
- 足すのはピントのあるペインではなく一覧のペイン（`homePane`。分けた元のペイン `PaneLayout.home`。左・上に分けても移らず、閉じた・なくなったら左上のペイン）だけ（1 つのタブだけを見せるために分けたペインに、ほかのチャットが流れ込まないように）。
- タブの × の「表示だけ消す」・タブのメニューの「閉じる」・ペインを閉じたチャットは `dismissed` に覚えて出し直さない（もう一度開けば出す。一覧から外れたら忘れる）。アーカイブ・削除のあとは覚えない（`closeTab(key, { dismiss })`）。一覧にないのに自分で開いたチャット（隠しているアーカイブ済みを検索から開いたなど）は `extra` で閉じるまで残す。
- 一覧のペインのチャットのタブは、サイドバーと同じ並び（サイドバーのまとめ方・並び順（最近動いた順 / 状態順 / 手動）・固定・アーカイブ済み。全プロジェクトの欄はサイドバーのプロジェクトの並び）にする（利用者の依頼。`features/sidebar/sidebarChatOrder.ts` の `useSidebarChatOrder` → `clusters/tabClusters.ts` の `orderLikeSidebar`。チャットのタブがある位置どうしで入れ替え、新しいチャット・ブラウザ・ターミナルのタブの位置は変えない。サイドバーにないチャット（自分で開いたアーカイブ済みなど）は後ろに今の順）。分けたほかのペインは自分で置いた並びのまま。
- 一覧のペインの中でチャットのタブをドラッグして落とすと、サイドバーの手動の並びを変える（利用者の依頼。`useTabStrip` の `reorderChatTab` → `useManualChatReorder`。落とした位置の右のタブ（なければ左のタブ）がサイドバーで同じまとまりのチャットなら、その前（後ろ）へ動かし、並び順を手動に切り替える。サイドバーの行のドラッグと同じ。`useTabDrag` の `barProps` の `reorderInPlace`）。同じまとまりのチャットのタブの隣でなければ、並びは変わらずサイドバーの順に戻る。
- どのチャットもタブにあるので、ボードのカードにタブで開いているかの印は付けない。アーカイブ済みはタブの列の「表示」のメニュー・まとまりの札の右クリックの「アーカイブ済みのチャットを表示」でも切り替える（サイドバーと同じ設定。`ArchivedChatsItem`）。

## ペインの分割（`layout/`）

- VS Code のエディターと同じく、いくつでも上下・左右のペインに分けられる。配置は木（葉 = ペイン `{ id, tabs, active }`、枝 = 分割 `{ dir: "row"（左右）| "column"（上下）, children, sizes（割合） }`）とピントのあるペイン `focused`・一覧のペイン `home`（`paneTree.ts`）。木はタブのキーだけを指し、1 つのタブは 1 つのペインにだけある。
- 変え方は純粋関数（`paneLayout.ts` の `placeTab` / `moveTab` / `returnToHome` / `splitPane` / `closeLayoutTabs` / `closePane` / `renameTab` / `reconcileLayout`、割合は `paneSizes.ts` の `setSplitSizes` / `equalizeSplit`）。移した結果空になったペインは消し、同じ向きの入れ子は `normalize` で 1 段にまとめる。分けた元・空のペインとして作ったペインは残し、最後の 1 つは消さない。ペインを閉じたときは、中のサイドバーと連動したチャットは一覧のペインへ戻し（`closePane` の `keep`）、ほかのタブは閉じる。
- 位置・落とす場所・境目の割合は `paneGeometry.ts`（`layoutRects` / `dropZoneAt` / `resizeAt` / `insertIndexAt` / まとまりの境目を見分ける `insertSlotAt`）。
- 表示: 分けていなければタブの列 → 中身。分けているときは中身（`.split-view`）の中に、ペイン（`PaneTabBar` ＋ タブがないときの `PanelEmpty`）・境目のつまみ `PaneSash`（ドラッグで割合、ダブルクリックで等分）を割合の位置で重ねる。タブの中身はいつも中身の直下に置いて style でペインの位置に重ね、分けても作り直さない（webview・ターミナル・入力中の文を保つ）。
- 分ける操作: 各ペインのタブの列の右端の「右に分ける」「下に分ける」（表示中のタブを新しいペインへ。タブが 1 つ以下なら空のペイン。右の欄は分けるボタンを置かない `noSplitButtons`。タブのドラッグ・右クリック・⌘\ で分ける）・「ペインを閉じる」（分けているときだけ。`.panel-pane-tools`）、タブの右クリック、⌘\（パネルにピントがあるとき右に分ける）、タブのドラッグ（`useTabDrag`。独自の MIME 型 `application/x-kickoff-panel-tab`。タブの列に落とすと移す・並べ替え、中身の端（1/4）に落とすとその側に分け、真ん中ならそのペインへ。ドラッグ中だけ中身の上に透明の覆い `.split-drop-cover` を置き、webview の上でも落とす場所を出す。ドラッグの絵は共通の写し `startDragGhost`（`src/renderer/src/CLAUDE.md` の「ドラッグの絵」）で、覆いはその `after` = 次の回に出す。パネルの外からタブにして落とすもの（ファイルタブの木の行）は `layout/externalTabDrag.ts` の `beginExternalTabDrag(欄, タブ)` で知らせ（MIME `application/x-kickoff-panel-external-tab`）、その欄の `useTabDrag` が同じ覆い・印で受けて、落としたらタブを開いてから移す・分ける）。
- ピントのあるペインは、分けているときだけ、そのペインのチャット欄の枠の色で示す（`PanelTabPage` の `split` と `.pane-focused`）。新しく開くタブ・新しいチャットはピントのあるペインに入る。

- タブには表示中の印の上の端の線のほかに線も枠も引かない（左右の枠・タブとタブの間の縦線もなし）。タブは角を丸めない。どのパネル（チャットのパネル・ボードの右・下のパネル・メモのパネル・チャットの画面の右の欄）でも、表示中のタブとその下の画面（見出し・会話・チャット欄・右の欄）を 1 枚の面に見せる: タブの列を画面より一段暗くし（ダークはサイドバーの地より暗く、ライトは少し灰色）、表示中のタブの地だけを画面と同じ `--bg` にして、その下の境目の線を切る（Chrome と同じ形。`styles/panel/side-panel-tab-sheet.css`。境目の線は枠ではなくタブの列の内側の影で引き、表示中のタブの下に地の色の影を 1px 落として塗りつぶす。枠だとタブより下の行になり、タブの列・並びの overflow で子が描けず、タブと画面の間に暗い 1px が残った。前の枠の 1px は下の余白で持ち、タブの列の高さは変えない。2 段のタブの列（サイドバー型のパネル）は `project-chat.css` の下の余白に 1px 足す）。画面がどのタブのものかを見て分かるようにするため（利用者の依頼）。画面の中の色は変えない（白を重ねると入力欄・カード・吹き出しとの差が縮むので、外側を暗くする）。地でつながるので、表示中のタブに下線を引かず、上の端に 1px の線（タブの色 `--tab-color`。なければアクセントの緑。Chrome・VS Code の表示中のタブと同じ）と太字の名前と地で示す（線の太さは利用者の指定）。右の欄（`.agent-panel`）のタブの列も、表示中の印は上の端の線（タブの色。子チャットは深さの色）と境目の塗りつぶしで同じ形にするが、地は暗くせず画面と同じにする（右の欄は外側の表示中のタブの面の中の部品なので、外側と同じ暗い帯を入れると面に穴が開いたように見え、隣に並ぶ別のパネルに見えた。一度暗くしてから、利用者の依頼で地だけ戻した）。子チャットの上の帯・サブエージェントの画面の見出し・指示の帯は、色の付いた地をやめて画面と同じ地にした（前は右の欄のタブの列を橙で薄く染め、子チャットの帯はサイドバーの地、サブエージェントの見出しはその色で染め、指示の帯は一段明るい地だった。種類は札の色・サブエージェントは見出しの左の帯で分かる）。名前のボタンにキーボードでピントが来ても外の枠は出さず、地で示す（枠の上下がタブの列に切り取られ、表示中のタブの両側に縦線だけが出ていたため）。
- ピン留めしたチャットのタブは、いちばん左（状態の印の前）にピンを出す（`PanelTab` の `pinnedIn` にチャットのプロジェクトの ID・`.panel-tab-pin`。60px 以下で名前と一緒に隠す）。サイドバーの「固定」・プロジェクトの見出しのピンとそろえ、まっすぐの `Pin` をそのプロジェクトの色（`projectHueStyle`）で塗る（前は傾けた灰色で、ほかと違って見えた）。
- 色のあるタブ（グループ別のまとまりの中のタブ = まとまりの色、右の欄のメモ・サブ・子 = 種類の色）は、どれも同じ見せ方にする: 色は `--tab-color` 1 つで、表示中のタブの上の端の線に使う。まとまりの頭の札と種類の札も、同じ「薄い地に色の文字」の札（種類の札は丸、まとまりの頭の札はタブと同じ高さの四角。`styles/panel/side-panel-tab-kinds.css`・`side-panel-tab-groups.css`）。以前はまとまりに色の地と下の 2px の線・濃い色に白文字の札を使っていて、右の欄の種類の色と作りがそろわず、色の面積も多かった。
- タブの列の何もないところの右クリックは、「表示」のボタンと同じメニュー。
- 「表示」のボタンは隠せる（利用者の依頼。`PANEL_VIEW_BUTTON_HIDDEN`。すべてのパネルで共通。初めは出す）: 「表示」のメニューの「既定に戻す」のすぐ上の「「表示」ボタンを出す」（チェック）と、設定の「表示」→「タブの列の「表示」ボタン」で切り替える。隠しても、タブの列の何もないところの右クリックで同じメニューを開け、そこから戻せる。「既定に戻す」で出すに戻る（チャットを出さない欄のメニューでも）。
- タブの列を隠せる欄（`SURFACES` の `hideableTabs`。チャットのパネル `board`）は、`CHAT_TAB_ROW_HIDDEN`（チャットの見出しと会話の何もないところの右クリックの「タブの列」・設定の「表示」→「チャットのタブの列」）で、どのペインのタブの列（左の道具も）も描かない（`Panel` の `tabsHidden`。根に `.tabs-hidden` を付け、分けているときはタブの中身を下げる高さ `--split-tabs-h` を 0 に）。チャットはサイドバー・ボードから切り替える。ボードの右のパネルでは、隠している間は左の道具の「横幅いっぱい ⇔ 元の幅」も出ないので、覚えた横幅いっぱい（`PANEL_MAXIMIZED`）を効かせず、ボードを横に残す（`usePanelWidth` の `maximizable`。覚えた値は残し、タブの列を戻せば効く。ボタンなしで横幅いっぱいのままだと、ボードを覆ったまま戻せなかった）。

## タブのまとまり（`clusters/`）

- まとめ方（「表示」のメニューの「チャットのまとめ方」。「まとめない / グループ別 / 作業場所別」。見出しはサイドバーと同じ「チャットのまとめ方」）は欄ごとに覚える（`useTabGrouping(surface)` → `panelTabGrouping(surface)`。欄の中のペインでは共通。初めはまとめない）。まとめ方とアーカイブ済みの切り替えはチャットのタブにだけ効く。
- どのまとまりに入るかは `useTabClusters`（種類の表の `cluster` で決め、まとまりはサイドバー・ボードと同じ `bucketChats` の決め方・同じキー）: グループ別はチャットのグループ／新しいチャットは作成先のグループ（もうないグループのものはグループなし）、作業場所別はチャットの作業場所（`workplaceOf`）／新しいチャットは始める作業場所（ふだんは本体。ワークツリーのチャットのタブの右クリックから始めた・作業場所を選び直したものはそのワークツリー）／ターミナルは開いたフォルダ、ブラウザ（グループ別ではターミナルも）は「その他」（`OTHER_CLUSTER`）。サイドバーと同じく、固定したチャットは「固定」（いちばん前）、アーカイブ済みは「アーカイブ済み」（後ろ。初めは畳む）に抜き出す。いくつかのプロジェクトのタブが並ぶときはプロジェクト名を前に添える。
- 並べるのは `clusterTabs`（`sortBuckets` と同じ順。まとまりの中はペインの並びのまま。一覧のペインのチャットのタブは、その前にサイドバーと同じ並びにしておく = 「サイドバーとの連動」）。グループ別では、自分で作ったグループをサイドバーと同じ並び（グループの店）で、チャットのタブがなくても札を出す（`seeds`。グループを作る・名前を変える・並べ替える・消すとサーバーの知らせですぐ追従する）。札を出すのは一覧のペインだけで、分けたほかのペインは自分で置いたタブだけの列にし、タブのないグループの札・「チャット」の札を出さず、札の数はそのペインのタブの数（`useTabStrip` の `home`）。
- 見た目: まとまりを 1 つの枠 `.panel-tab-group` に入れ、頭の札と、表示中のタブの色（`--group-color` → `--tab-color`）と、まとまりどうしの間隔でどこまでが 1 つかを見せる。中のタブの地は頭の札と同じ色（`--group-tint`。「その他」は札と同じ `--bg-elev`。乗せると少し濃く。表示中のタブは下の画面と 1 枚に見せるので画面の地のまま。利用者の依頼）。色はサイドバーのまとまりの見出しと同じ（`useTabClusters` の `hueOf` → `features/chatList/bucketHues.ts`。プロジェクトのまとまりすべてから被らないように決めるので、隠したグループ・開いていないタブで色が変わらない。自分で作ったグループは覚えた色 `ChatGroup.hue`、作業場所はブランチの印 `WorktreeChip` と同じ色）。「その他」は色なし `.plain`。「まとまりを色付きで表示」（`PANEL_TAB_GROUP_COLORS`。すべての欄で共通。初めは色付き）を外すと、どのまとまりも「その他」と同じ色なしにする。切り替えは「表示」のメニューの「チャットのまとめ方」の下（まとめているときだけ）と、札の右クリック（`BucketColorItem`）。「既定に戻す」でも色付きに戻る。まとまりの枠も一緒に細くなり、どこまで細くできるかは見せているタブの数 `--cluster-tabs` から決める。札よりタブを先に細くする。
- 札（`TabClusterHead`）は 1 つの四角い札を左右に区切った形（`.panel-tab-cluster-pill`。タブと同じ高さの四角。利用者の依頼で、前は低い丸い札で、どこまでが 1 つのまとまりか分かりにくかった。すぐ右のタブとの間は、ほかのタブどうしの間（2px）と同じ（一度は空けずに付けたが、利用者の依頼でそろえた）。色の地は札に付け、中の 2 つのボタンは透明で乗せた方だけ明るく）: 左 = 名前（押すと、まとまりのチャットをすべて作業中 → 回答待ち → 未読 → 既読 → アーカイブ済みに分けた一覧 `StateChatsPopover`（`chatsByState` の `all`）。行でそのチャットのタブを開く。一覧はタブの列に切り取られないよう画面に固定 `.cluster-chats-popover`。一覧に新しいチャットのボタンは置かない（利用者の依頼で消した。前はいちばん下に「「グループ名」で新しいチャット」などがあった。新しいチャットはタブの列の新しいタブのボタン・タブの右クリックから））、右 = まとまりのタブを畳む・開く（`.panel-tab-cluster-fold`。開いているときは「‹」、畳んでいるときはまとまりのタブの数 `tabCount`。表示中のタブを残しているかに関係なく同じ形。幅は「‹」と 1・2 桁の数で 14px（利用者の依頼で細くした。前は 23px ほど）、3 桁の数はその分だけ広がる。右上に未読の数があるときは右を 8px 空ける）。名前は 2〜3 文字までは残し、中のタブを先に細くする。札は中身より細くしない（`grid` の `minmax(calc(2.5em + 14px), auto) auto` と `min-width: min-content`。中身より細く縮むと、右の「‹」がはみ出して隣のタブに隠れた）。札の角に、まとまりのチャットの状態ごとの数 `StateCornerCounts`（数えるのはタブで開いているチャットと、一覧のうち同じまとまりに入るもの。札の内側の角に小さめの丸で置き（外へはみ出すとタブの列に切り取られる）、数がある側は札の余白を広げて名前に重ねない）。チャットの数（サイドバーの見出しと同じ数え方。表示だけ消したタブも数え、下書きは数えない）は名前の説明に出す。「その他」は押せない。
- 「まとまりの名前を省略」（`PANEL_TAB_CLUSTER_SHORT`。すべての欄で共通。初めは省略しない。利用者の依頼）: 札の名前を頭の 1 文字だけにする（`clusterInitial`。グループはグループ名・本体は「本」・ワークツリーはブランチ名・固定などは「プロジェクト · 」を除いた名前の頭。絵文字も 1 文字として扱う）。2〜3 文字ぶんの下限を外し（`.panel-tab-cluster-pill.short`）、1 文字は省かない。名前は乗せたときの説明に出す。まとめないときの「チャット」の札は省略しない。切り替えは「表示」のメニューの「まとまりを色付きで表示」の下（まとめているときだけ）と、札の右クリック（どちらも `clusters/ClusterShortItem`）。「既定に戻す」でも省略しないに戻る。
- グループ別では、自分で作ったグループをタブの列から隠せる（`useHiddenTabGroups`。隠すグループ `PANEL_HIDDEN_GROUPS` と「チャットのないグループを隠す」`PANEL_HIDE_EMPTY_GROUPS`（初めは出す）。どちらもすべてのパネル・ペインで共通）。選ぶのは「表示」のメニューの「グループ（タブの列）」（`HiddenGroupItems`: 「表示するグループ ▸」のチェック（押しても閉じない・「すべて表示」）と「チャットのないグループを隠す」）と、札の右クリック（「「グループ名」をタブの列から隠す / 表示する」と、「表示」のメニューと同じ 2 つ）。No Group・固定・アーカイブ済みは隠せない。外すのは `shownClusters`（チャットのない = タブもサイドバーのチャットもない）。隠したグループでも、ペインで表示中のタブがあれば札ごと畳んだ形で残し（どのタブか分かるように）、札の右の数を押すと隠すのをやめる。
- 畳んだまとまりは、そのペインで表示中のタブだけを残す（`visibleClusterTabs`。隠したチャットを一覧から開けば表示中になって出る。見た目の並び `display` にも入れない）。隠れたタブだけになったまとまりは札だけになる。開閉は `useFolds("panel", …)`（すべてのパネル・ペインで共通）。札の右クリックの「タブを畳む / 表示する」も同じ。
- 札の右クリック（プロジェクトの分かるまとまりだけ）: 「新しいグループを作成…」（`promptDialog` → `api.createGroup`。グループ別のときだけ `canCreateGroup`。作業場所別の本体・ブランチの札はグループと関係がないので出さない）・自分で作ったグループの札では「「グループ名」をタブの列から隠す / 表示する」、グループ別のときは区切り線の下に「表示」のメニューと同じ「表示するグループ ▸」「チャットのないグループを隠す」（`HiddenGroupItems`）とどのまとめ方でも「まとまりを色付きで表示」（`BucketColorItem`）・「まとまりの名前を省略」（`ClusterShortItem`）・「アーカイブ済みのチャットを表示」（`features/chatList/ArchivedChatsItem`。「表示」のメニューと同じ部品で、サイドバーと共通の設定。利用者の依頼。どれも札の `menuExtra`）、自分で作ったグループの札では区切り線の下に「「グループ名」を削除…」（サイドバーと同じ `confirmDeleteGroup` で確かめてから。中のチャットはグループなしに戻る）。札の右クリックのいちばん上には、そのまとまり（グループ・No Group・本体・ワークツリー）で始める「新しいチャット」を置き、チャットの右クリックと同じくグループと作業場所の札を添える（`NewChatItem`。作成先は `newChatPlaceOf`。右クリックした札のペインに開く `onNewChat`。チャットを出す欄だけ。フォルダなし・以前のブランチ・固定・アーカイブ済み・その他の札では出さない。利用者の依頼。前は右クリックに置いていなかった）。札を押した一覧には置かない。
- 自分で作ったグループの札はつかんでドラッグし、同じプロジェクトのほかのグループの枠に落とすと並びを入れ替える（`useClusterReorder`。サイドバーと同じ `useReorder` で、入る位置に縦の線・動かしているまとまりは薄く。`api.reorderGroups` で DB の並びを変えるので、サイドバー・全プロジェクトのボードのグループの列・ほかのパネルの札も同じ並びになる。グループなし・作業場所・その他・ほかのプロジェクトのグループには落とせない）。
- グループ別のとき、チャットのタブをつかんで同じプロジェクトのほかのグループ・「No Group」の枠に落とすと、そのチャットをそのグループへ移す・グループから外す（`useClusterTabDrop`。サイドバー・全プロジェクトのボードのグループの列へのドラッグと同じ `api.setChatGroup`）。送る前の新しいチャットのタブは作成先のグループを変える（`setDraftGroup`）。移せるかは純粋関数の `clusterTabDrop`（いまと同じグループ・子チャット（グループに入らない）・ほかのプロジェクト・固定・アーカイブ済み・作業場所・その他の枠は移さない）。移せる枠に重ねている間は、サイドバーと同じ点線の枠と薄い地（`.panel-tab-group.drop-target`）。落とす位置の印とペインの中の並べ替えはふだんのタブのドラッグ（`useTabDrag`）のまま。グループの札の並べ替えと同じ枠に付けるので、受け口は `joinDropHandlers` でつなぐ。
- まとめないときも、タブの列の左端（横にスクロールしても動かない位置）に同じ札「チャット」（`TabClusterHead` の `all`。控えめな地 `.panel-tab-cluster.all`、タブの数は出さない）を置き、パネルのチャット全体の状態ごとの数と一覧を出す。チャットが 1 つもなければ出さない。
- ドラッグで落とす位置は見た目の並びで印を付け、`paneIndexOf` でペインの並びの位置に直して移す（`useTabDrag` の `toPaneIndex`）。まとまりの境目では、次のまとまりの枠に入る前（前のまとまりの最後のタブの右半分・枠の間）なら前のまとまりの最後の後ろに、枠（頭の札から）に入れば次のまとまりの最初の前に印を付ける（`paneGeometry.ts` の `insertSlotAt` の `after`。利用者の指摘。前はどちらも「次のタブの前」で、前のまとまりの最後に入れたくても印が次のまとまりの先頭に出た）。`after` で落としたときの一覧のペインの並べ替え（`reorderChatTab`）は左のタブを先に見る。

## 下書き（送る前の新しいチャット）

- 下書き（`panelDrafts.ts` の `PanelDraft`）は、どの欄のどのタブか・作成先・書きかけの文・表示しているか。すべての欄の分はサイドバーの各プロジェクト（`DraftRows`）・⌘⇧A のいちばん上・全プロジェクトのボードの「下書き」の列（`useAllDrafts`）、プロジェクトのボードの分（そのボードのパネルと同じプロジェクトのチャット欄）はボードの「下書き」の列（`usePanelDrafts`）に出す。押すとその欄で開き、画面に出ていない欄のものは、その画面へ移ってから開く（`openDraft`。`panelScreen`）。消すのは `discardDraft`、固定を付け外しするのは `togglePinDraft`（タブの `pinned`）、作成先のグループを変えるのは `setDraftGroup`（サイドバーでグループへドラッグしたとき・右クリックの「グループを変更」。欄が画面にあればそのタブを、なければ覚えている内容を書き換える）、名前を付けるのは `setDraftTitle`（タブの `title`。空なら外す。出すときは `draftTitleOf`）、右・下に分けて開くのは `openDraftSplit`、別のプロジェクトへ移すのは `moveDraftToProject`（移す先のプロジェクトのチャットのパネルに新しいチャットのタブを開いて、書きかけの文・添付・名前・固定を入れ、元を消す。`panelActions(key).openNew` は開いたタブのキーを返す）。右クリックの項目は `features/chat/DraftMenuItems`、タブの右クリックの下書きは `draftOfPanelTab`。
- 書いている途中の文は `Composer` の `onTextChange` からタブの `draftText` に入れ、カードに初めの 3 行を出す。
- 下書きのタブだけは再起動しても消えないよう、`draftPersistence.ts` で localStorage（`NEW_CHAT_DRAFTS`。パネルごとのタブの JSON）にも残し、起動したら閉じた欄のタブとして戻す（以前の全プロジェクトのボードのパネル `kanban:all` と、全プロジェクトの画面のフッター `bottom:all` に残っていたものは、チャットを出す欄がないので、作成先のプロジェクトのボードのパネルへ移して残し直す `moveAllProjectsDrafts`）。書きかけの文は `NewChatPane` が入力欄に 1 回だけ戻し、隠れているタブではピントを移さない（`fill` の `focus: false`）。送った・閉じたら消え、消したプロジェクトの分は App が `forgetDraftsOfMissingProjects` で片付ける。送る前の添付（アップロード済み）はタブの `draftAttachments` に残し、入力欄が戻す（`PanelTabPage` の `savedAttachments`。外すまで消さない）。送信待ちの指示から始めたタブの添付（`seed.attachments`）は、タブにまだ添付を残していないときだけ入れる（外した添付を戻さない）。

## 欄の殻

- プロジェクトのチャットのパネル（`board`。`kanban:<プロジェクト>`）は、設定の「チャットを開く場所」（`CHAT_PLACEMENT`。`useChatPlacement`）で置き場所が変わる。どちらも同じパネル・同じ状態なので、切り替えても開いているタブ・分割はそのまま。共通の部分（`usePanel`・新しいチャットを送ったら URL にする・サイドバー・検索などから開いたチャット（URL）をパネルで開く `useBoardFocus`・タブで選んだチャットを URL にする `useShownChatInUrl`）は `useProjectChatsPanel`。タブで選んだチャット（ピントのあるペインで表示中のタブが変わったとき）も URL にし（差し替え。戻る・進むの履歴は増やさない）、サイドバーの行を選択中にする（利用者の依頼。前はカードから開いた・新しいチャットを送ったときだけ URL にしていて、タブを選んでもサイドバーの強調が前のチャットのままだった）。チャットでないタブ（新しいチャット・ブラウザ・ターミナル）にしたらプロジェクトの画面に戻して強調を外し、新しいチャットのタブはサイドバーの下書きの行を選択中にする（`DraftRows` の `useDraftSelected`）。はじめて描いたときは URL を変えない（URL で開いたチャットを、前に表示していたタブで上書きしないため）。ボードは開く先を `board/boardChats.ts` の `BoardChats`（右のパネルなら `panelChats`、チャットタブなら `useChatsTabLinks`）だけで見て、置き方で分岐しない（カード・「新規」・グループの列の＋・下書き）。
- チャットタブ（`ChatsTab`。置き方が `separate`（初め）のとき。プロジェクトの左の縦の列の「チャット」タブ `#/projects/:id/chats`）: パネルを横幅いっぱいに出す。チャット・新しいチャットの URL はこのタブで開き（`app/router.ts` の `boardTabOf`）、ボードのカード・下書きのカードを押すとこのタブへ移る（画面に出ていない下書きの移り先 `panelScreen` もこのタブ）。パネルはいつも開いておき（Esc・最後のタブを閉じても閉じない。タブがなければ案内）、閉じるボタン・幅のつまみ・横幅いっぱいの切り替えは出さない（`PanelFrame` の `fixed`）。ボードには右のパネル・その開閉ボタンを置かない。置き方が `together` のときにこのタブの URL へ来たら、ボードで出す。
- ボードの右のパネル（`useBoardPanel`。置き方が `together` のとき）: プロジェクトのボードだけに置く（全プロジェクトのボードはチャットをそのプロジェクトへ移って開くので持たない）。新しいチャットはそのプロジェクトで始める。カードから開いた・新しいチャットを送ったチャットを URL にもし（サイドバーで強調され、戻る・進むで行き来できる）、サイドバー・検索などから開いたチャット（URL）をパネルで開く（`features/board/useBoardFocus.ts`）。開閉のボタンはボードのツールバーの右端の `PanelToggle`（閉じていて開いたタブがあれば数を出す）。
- 幅（`usePanelWidth`。左端のつまみで変えて覚える `PANEL_WIDTH`）: パネルは外枠・角の丸み・影を付けず、ボードとの境目に左の 1 本線だけを引き、開いているときは画面の右・下の余白まで伸ばして端に付ける。開閉ではタブの列と中身を開き終えたときの幅 `--panel-shown` のまま左端にそろえ、パネルの枠で切り取って右から滑り込ませる（動いている間に中身を並べ直さない。切り取りはパネル自身で行い、`.board-body` に `overflow-x: clip` を付けない）。横に残るボードが狭すぎる（`MIN_BOARD_WIDTH`（200px）未満）ならボードを覆う（`covering`）。横幅いっぱいの切り替え（`PANEL_MAXIMIZED`）は覆っているときも隠さず「元の幅に戻す」として出し、押すとボードが残る幅（`fitWidth`）まで縮める。それでもパネルの最小の幅に足りないほど狭ければ押せなくする（`canRestore`）。覆っている・横幅いっぱいのときは `.board-body.panel-full` で見えないボードとの間隔も消す（列の指定はふだんと同じ形のままパネルの幅だけを 100% にする。形を変えると、ブラウザが間をなめらかにつながない）。横幅いっぱいを切り替えて幅が動いている間（`stretching`）は、右端は動かず左端だけが伸び縮みするので、中身を枠の幅に合わせて並べ直す。左端のつまみのドラッグ中は判定で張り付けず指の位置どおりの幅にし、離したときにボードが狭すぎれば覆う。
- チャット欄（`useProjectChat` ＋ `ProjectChat`）: 画面の右端の、どのタブでも開ける欄（ボードの右のパネルとは別のもの）。全プロジェクトの画面でも開け、そのときはサイドバーで最後に選んでいたプロジェクト（`useFallbackProject`。もうなければ先頭。⌘N の作成先と同じ）のチャット欄を出す（チャットは出さず、ターミナルとブラウザだけ。`noChat`。チャットのタブは閉じずに隠し、そのプロジェクトの画面ではそのまま出る）（以前はプロジェクトの画面だけで、全プロジェクトの画面では右上の開閉ボタンごと消えていた）。プロジェクトが 1 つもなければ出さない。App のレイアウトの 3 列目に置き、下のパネルより下まで伸ばす。開閉は右上のレイアウトの開閉（`app/LayoutToggles`）か ⌥⌘B。開閉はプロジェクトごと、幅はアプリ全体（`PROJECT_CHAT_WIDTH`）。真ん中に `--main-min-w` を残すところまでしか広げない（`--chat-shown`）。閉じても要素は残し（幅 0）、書きかけの文をなくさない（閉じ終えたら `visibility: hidden` にし、はみ出した中身のドラッグ領域をボードの上に残さない。`styles/CLAUDE.md`）。幅が狭いので、タブの列は 2 段にする: 上の段（信号機ボタン・右上のレイアウトの開閉と同じ行）にタブ、下の段に道具（DOM は変えず `project-chat.css` の `order` と幅いっぱいの `::before` で折り返し、分けたペインのタブの列の高さ `--split-tabs-h` も 2 段分にする）。
- 下のパネル（`useBottomPanel` ＋ `BottomPanel`。VS Code の「パネル」と同じ）: どの画面でも ⌃\` / ⌘J で開閉（全プロジェクトの画面ではチャットを出さず、ターミナルとブラウザだけ。`noChat`）（ターミナルの中で押しても効くよう、ほかより先に受け取る）。高さは上の端のつまみのドラッグ（`BOTTOM_PANEL_HEIGHT`）、最大化と閉じるはタブの列の道具。タブ・開いているかはプロジェクトごと（全プロジェクトの画面は別）。Esc では閉じない。見せている最後のタブを閉じると閉じる（閉じたら最大化もやめる）。閉じても要素は残し（高さ 0。閉じ終えたら `visibility: hidden`）、シェルはメインプロセスで動き続ける。フッターにピントがあるときの ⌘\ で右に分ける。開閉は右上の `LayoutToggles`（下の帯には置かない）。
- 右の欄（`AgentSplit`。`agents`。サブエージェントの画面と、変更・ファイルのタブ）: チャットの画面を、左の会話と右の欄に横に並べる殻（`ChatView` が自分の中身を包む）。右の欄は通常のパネル（タブ・上下左右の分割・タブのドラッグ・境目・⌘\・タブの右クリック）をチャットのタブの中に入れ子にしたもの。幅は左端のつまみのドラッグで変えて覚え（`SUBAGENT_PANEL_WIDTH`。アプリ全体）、左の会話の残りが `MIN_MAIN_WIDTH`（320px）より狭くなる幅まで広げる・チャットのタブが狭いときは右の欄で左の会話を覆う。横幅いっぱいの切り替えのボタンは置かない（`useCoverableWidth` に `maximized` を渡さない）。覆っている間、左の会話は描いたまま隠す（`inert`・覆い終えたら `visibility: hidden`）。流れの中のカードへ移るとき（`revealSubagent`・`show`）は並べる形に戻し、狭くて戻せなければ右の欄を閉じる（`SidePanelHandle.uncover`）。一度タブを開いたら閉じても右の欄の中身を残す（入力中の文・読んでいた位置）。右の欄の中はどのタブでも、このチャットを足す先のチャットとする（`MainChatContext` と `SideSelectionAttach`。右クリックの、足す先のチャットの名前の組と、選んだときの「チャットに追加」。`features/chat/CLAUDE.md`）。パネルの外（`PanelHostContext` がない）では置かない。開け閉めは、チャットの見出しの右端のボタン（`AgentPanelToggle`。`panelActions(key).toggle`。タブがなければ空の欄の案内）・欄のタブの列の右端の閉じる（右上のペイン）・Esc。
- 右の欄の ⌘F（`AgentPanelFind`）: ピントが右の欄の中にある（どこにもピントがなければ、最後に右の欄を押した）とき、表示しているタブの中を探す。メモ（CodeMirror）はエディタの検索の欄（`@codemirror/search`。見えていない行も探せる。文言は日本語 `SEARCH_PHRASES`）、ファイルの編集（Monaco）はエディタの検索の欄（`MonacoFindBar`）、子チャットはその画面のチャットの検索（`ChatFind`）に任せ、ほか（サブエージェント・変更・ファイル）は欄の右上（タブの列のすぐ下）に検索の欄を出し、見えている文字に印を付ける（ページの ⌘F と同じ部品 `ui/FindBar.tsx`。画面全体の `CLAUDE.md` の「ページの ⌘F」）。エディタの検索を開くのは、ページの ⌘F と共通の `features/editor/editorFind.ts` の `openEditorFind`（前は、ピントが外にあるときの Monaco のファイルを、見えている行の文字だけで探していた）。親のチャットの画面のキー（⌘F・⌘↓ など）は、右の欄の中では受け取らない（`chatHotkeys.ts` の `isChatTarget`。押した所はいちばん内側のチャットの画面で数える）。
- 幅と覆う決まり（`hooks/useCoverableWidth`）はボードの右のパネル（`usePanelWidth`）と共通: 欄の幅・横幅いっぱい・残す側が狭すぎれば覆う（`leavesNarrowRest`）・元の幅に戻すときは残す側が入る幅まで縮める（`fitWidth` / `canRestore`）・開閉で動いている間は開き終えたときの幅（`shownVar`）のまま切り取る。
- 入れ子のパネル: `Panel` が自分の中身に `PanelHostContext` で自分を渡し、チャットの画面はそこから受け取って右の欄を描く（Panel → `PanelTabPage` → チャットの画面 → Panel と import すると輪になるため）。根のクラスは `rootClass`（`agent-panel`。外側の `.board-panel` の規則が効かないように）、根に `data-panel-key`。キーは、ピントのあるいちばん内側の欄だけが受け取る（⌘\ は `focusedPanelKey()` がその欄のときだけ、外側の欄の Esc は `focusInNestedPanel` なら内側に任せる）。タブのドラッグは欄ごとの `dragging` で受けるので、欄をまたいで移らない。外側の欄のタブの列の CSS（チャット欄・フッター）は `:not(:where(.agent-panel *))` で内側に効かせない（`styles/CLAUDE.md`）。
- 欄の開閉の動きは `--panel-motion-duration` / `--panel-motion-ease` にそろえる（`styles/CLAUDE.md`）。
