# タブの入れ物（`features/panel`）

チャット・新しいチャット・ブラウザ・ターミナルのタブを並べる欄（サブエージェントはタブにせず、チャットの流れの中のカードで見せる。`features/chat/CLAUDE.md`）。3 つの欄（ボードの右のパネル・画面の右端のチャット欄・下のパネル（フッター））は同じ `Panel` / `usePanel` で、違いは `surfaces.ts` の `SURFACES` と、欄の殻が渡す `frame` だけ。タブの中身のうちチャットは `features/chat/CLAUDE.md`、ターミナル・ブラウザ・▾ のメニューは `features/terminal/CLAUDE.md`。

| フォルダ | 中身 |
|---|---|
| 直下 | `Panel`（表示）・`usePanel`（状態と操作を束ねる）・`surfaces.ts`（欄の決まり）・`PanelTools`（タブの列の左の道具）・`PanelEmpty` |
| `state/` | 状態（`panelState.ts` の `panelReducer`・店 `panelStore.ts`・操作 `panelActions.ts`）・サイドバーとの連動（`linkedTabs.ts`・`useLinkedChats.ts`）・表示するタブの種類（`panelKinds.ts`）・下書き（`panelDrafts.ts`・`draftPersistence.ts`） |
| `layout/` | ペインの分割（形 `paneTree.ts`・変え方 `paneLayout.ts`・割合 `paneSizes.ts`・位置 `paneGeometry.ts`・境目 `PaneSash`・タブのドラッグ `useTabDrag`） |
| `tabs/` | タブの種類の表（`tabKinds.ts`）・型（`panelTypes.ts`）・タブの列（`PaneTabBar` / `PaneTab` / `PanelTab` / `PanelTabAdds`）・中身（`PanelTabPage`・`NewChatPane`）・メニューと道具（`TabMenu` / `TabKindsButton` / `TabGroupingButton` / `TabArchiveToggle`） |
| `clusters/` | タブのまとまり（`useTabClusters`・`tabClusters.ts`・`useTabStrip`・札 `TabClusterHead`・並べ替え `useClusterReorder`） |
| `board/` `projectChat/` `bottom/` | 欄の殻（大きさ・開閉・ショートカット）: `useBoardPanel` ＋ `usePanelWidth` ＋ `PanelToggle` / `useProjectChat` ＋ `ProjectChat` / `useBottomPanel` ＋ `BottomPanel` |

## 欄の決まり（`SURFACES`）

欄ごとの違いは作る側・描く側で分岐させず `SURFACES` に集める（覚える名前の頭 `memoryPrefix`・初めに見せるタブの種類 `defaultKinds`・Esc で閉じるか・最後のタブを閉じたら欄も閉じるか・タブがないまま開いたときに始めるもの・開閉を覚える設定・閉じるボタン・大きくする切り替え・タブがないときの案内・ツールバーの置き方のメニュー・クラス）。

| | ボードの右のパネル `board` | チャット欄 `side` | 下のパネル `bottom` |
|---|---|---|---|
| 初めのタブの種類 | チャット | ブラウザ・ターミナル | ターミナル・ブラウザ |
| Esc で閉じる | 閉じる | 閉じない（文字を打つ欄） | 閉じない（ターミナルで使う） |
| 最後のタブを閉じたら | 閉じる | 開いたまま | 閉じる |
| 開いたときに始めるもの | — | 新しいチャット | ターミナル（開く場所が 1 つのとき） |
| 大きくする | 横幅いっぱい | — | 最大化 |

- 状態は欄・画面ごとに `panelKey(surface, scope)`（`kanban:<プロジェクト | all>`・`side:<プロジェクト>`・`bottom:<プロジェクト | all>`）で覚える。ボードはカンバンとグループのボードで同じパネル（列の分け方を切り替えても開閉・タブ・分割はそのまま）。`memoryPrefix` は下書きの保存のキーにも使うので変えない。

## 状態（`state/`）

- 1 つの欄の状態（`PanelState`: タブ・分割の配置・開いているか・サイドバーとの連動の覚え）は店（`panelStore.ts`）が欄・画面ごとに覚え、変えるのはすべて純粋関数の `panelReducer`（閉じたタブの後始末・保存は店）。部品は `usePanelState` で読み、`dispatchPanel` で変える（画面に出ていない欄も、サイドバーの下書きなどから同じ方法で変えられる）。操作は `panelActions(key)`（部品の外からも使え、`usePanel` が束ねる）。タブやプロジェクトを切り替えて戻っても元どおり。覚えるのはアプリを閉じるまで（チャット欄の開閉だけはプロジェクトごとに `projectChatOpen`）。
- `usePanel` が返すもの: `open(chat, focus?)` / `openNew(target, seed?)` / `openBrowser` / `openTerminal`（自分で開くタブはピントのあるペインに足し、すでにあればそのペインで表示。欄も開く。隠している種類のタブなら、その種類を出す）・`closeTab(key, { dismiss })`・`isShowingTab` / `isShowing(chatId)`（どれかのペインで表示中か）・`shownTabOf(pane)`・`chatOf(tab)`（タブのチャット。サイドバーの一覧にあれば最新、なければタブの中のチャットから届いたもの）・ペインの操作（`splitPane` / `moveTab` / `closePane` / `returnToHome` / `focusPane` / `resizeSplit` / `equalizeSplit`）など。
- 配置を変える操作は、いまのタブにそろえた配置から変える（自動で足したタブがまだ配置に入っていないまま変えると、そのタブを移す・分ける操作が何もしなかった）。
- タブの中身は `PanelTabPage`（種類ごとの中身は `PAGES`）。表示していないタブも hidden で残し、入力中の文・スクロール位置を保つ。チャットのタブはサイドバーと連動して自動で増えるので、中身は初めて表示したときに作る（`TabKindSpec.lazy` と `Panel` の `mountedTabs`）。

## タブの種類（`tabs/tabKinds.ts`）

種類（`chat` / `new` / `browser` / `terminal`。型は `panelTypes.ts` の `PanelTab`）ごとの違い（キーの決め方・「表示するタブ」のどれに入るか `shows`・アイコンと名前・どのプロジェクトのものか・どのチャットのものか（そのチャットを消したら閉じる）・中身を作る時・閉じたときの後始末（ターミナルはシェルも止める）・どのまとまりに入るか）は、種類で分岐させずに `TAB_KINDS` から引く。チャットのタブのキーは `chatKey(id)`（同じチャットは 1 つのタブ）、ほかは押すたびに新しいキー（`newTabKey`。ターミナルのキーは裏のシェルのキーにも使うので乱数を添える）。

- チャットのタブは吹き出しの代わりに状態の印 `StatusSlot`（サイドバーの行と同じ）を出し、未読・失敗は名前を太字（`.panel-tab.unread`）。名前のダブルクリックでタブの中で名前を変える（`PanelTab` の `onRename` / `editor`。`useChatRename`）。チャットの見出しには名前を出さない。
- どのグループのチャットかは、タブの名前の後ろに控えめに「· グループ名」（`PanelTab` の `group`、`.panel-tab-group-name`。送る前の新しいチャットは `groupName`）。グループ別にまとめているときは出さない。
- タブの × は種類による: チャットは `closeChatWithChoice`（表示だけ消す・アーカイブ・削除）、分けたペインのサイドバーと連動したチャットは聞かずに一覧のペインへ戻す、ほかはそのまま閉じる。右クリックは `TabMenu`（右・下に分けて開く・ペイン n へ移す（一覧のペインに「（一覧）」と添える）・一覧のペインに戻す・閉じる。チャットのタブにはチャットのメニューの項目 `ChatMenuItems` も並べる）。
- 新しいチャットのタブ（`NewChatPane`）: 最初のメッセージを送ると、同じペインの同じ位置のまま、できたチャットのタブに置き換わる（`replaceWithChat`）。送信待ちから始めたときは `seed` の文と添付をチャット欄に入れる。新しいチャットの URL は開いたらボードに戻し、ボードを開き直しても増やさない。作業中のチャットがある作業場所に送るときの確かめは `features/worktree/CLAUDE.md`。

## 表示するタブの種類（`state/panelKinds.ts`）

タブの列の `TabKindsButton`（目のアイコン）で、欄に出すタブの種類（チャット（新しいチャットも）・ブラウザ・ターミナル）をチェックのメニューで付け外しする（`usePanelKinds`。保存は欄ごとの `panelTabKinds(surface)`、未保存なら `SURFACES` の `defaultKinds`。最後の 1 つは外せない）。隠した種類のタブは閉じずに残し（シェル・ページ・書きかけの文を保つ）、タブの列・中身・新しいタブのボタン・`PanelEmpty` に出さない（表示中のタブを隠したら `shownActiveOf` で見せている種類の最初のタブ）。チャットを隠している欄では、まとめ方・アーカイブ済みの切り替え・「チャット」の札・タブのないグループの札も出さず、サイドバーのチャットを読みもしない（表示に戻したらそろえる）。

## サイドバーとの連動（`state/linkedTabs.ts`）

- パネルのチャットのタブは、サイドバーに出ているチャット（`useLinkedChats`。チャットの店から読み、全プロジェクトはしまったプロジェクトとタグの絞り込みに合わないものを除く。アーカイブ済みは `SIDEBAR_SHOW_ARCHIVED` のときだけ）に、一覧が届いてから `syncLinkedTabs` でそろえる: 一覧にあってタブのないチャットは足し、一覧から外れたチャット（アーカイブして隠した・移した・消した）のタブは閉じる。
- 足すのはピントのあるペインではなく一覧のペイン（`homePane`。分けた元のペイン `PaneLayout.home`。左・上に分けても移らず、閉じた・なくなったら左上のペイン）だけ（1 つのタブだけを見せるために分けたペインに、ほかのチャットが流れ込まないように）。
- タブの × の「表示だけ消す」・タブのメニューの「閉じる」・ペインを閉じたチャットは `dismissed` に覚えて出し直さない（もう一度開けば出す。一覧から外れたら忘れる）。アーカイブ・削除のあとは覚えない（`closeTab(key, { dismiss })`）。一覧にないのに自分で開いたチャット（隠しているアーカイブ済みを検索から開いたなど）は `extra` で閉じるまで残す。
- どのチャットもタブにあるので、ボードのカードにタブで開いているかの印は付けない。アーカイブ済みはタブの列の `TabArchiveToggle`（まとめ方のボタンのすぐ右。出しているときはアクセントの色）でも切り替える（サイドバーと同じ設定）。

## ペインの分割（`layout/`）

- VS Code のエディターと同じく、いくつでも上下・左右のペインに分けられる。配置は木（葉 = ペイン `{ id, tabs, active }`、枝 = 分割 `{ dir: "row"（左右）| "column"（上下）, children, sizes（割合） }`）とピントのあるペイン `focused`・一覧のペイン `home`（`paneTree.ts`）。木はタブのキーだけを指し、1 つのタブは 1 つのペインにだけある。
- 変え方は純粋関数（`paneLayout.ts` の `placeTab` / `moveTab` / `returnToHome` / `splitPane` / `closeLayoutTabs` / `closePane` / `renameTab` / `reconcileLayout`、割合は `paneSizes.ts` の `setSplitSizes` / `equalizeSplit`）。移した結果空になったペインは消し、同じ向きの入れ子は `normalize` で 1 段にまとめる。分けた元・空のペインとして作ったペインは残し、最後の 1 つは消さない。ペインを閉じたときは、中のサイドバーと連動したチャットは一覧のペインへ戻し（`closePane` の `keep`）、ほかのタブは閉じる。
- 位置・落とす場所・境目の割合は `paneGeometry.ts`（`layoutRects` / `dropZoneAt` / `resizeAt` / `insertIndexAt`）。
- 表示: 分けていなければタブの列 → 中身。分けているときは中身（`.split-view`）の中に、ペイン（`PaneTabBar` ＋ タブがないときの `PanelEmpty`）・境目のつまみ `PaneSash`（ドラッグで割合、ダブルクリックで等分）を割合の位置で重ねる。タブの中身はいつも中身の直下に置いて style でペインの位置に重ね、分けても作り直さない（webview・ターミナル・入力中の文を保つ）。
- 分ける操作: 各ペインのタブの列の右端の「右に分ける」「下に分ける」（表示中のタブを新しいペインへ。タブが 1 つ以下なら空のペイン）・「ペインを閉じる」（分けているときだけ。`.panel-pane-tools`）、タブの右クリック、⌘\（パネルにピントがあるとき右に分ける）、タブのドラッグ（`useTabDrag`。独自の MIME 型 `application/x-kickoff-panel-tab`。タブの列に落とすと移す・並べ替え、中身の端（1/4）に落とすとその側に分け、真ん中ならそのペインへ。ドラッグ中だけ中身の上に透明の覆い `.split-drop-cover` を置き、webview の上でも落とす場所を出す）。
- ピントのあるペインは、分けているときだけ、そのペインのチャット欄の枠の色で示す（`PanelTabPage` の `split` と `.pane-focused`）。新しく開くタブ・新しいチャットはピントのあるペインに入る。

## タブの列（`tabs/PaneTabBar`）

- 並び: 左に道具（`PanelTools`。左上のペインだけ。閉じる（欄の決まりで先頭か最後。チャット欄は右上のレイアウトの開閉で閉じるので出さない）・表示するタブの種類（閉じるのすぐ右、チャット欄では左端。ほかの道具の前提になるため）・まとめ方（`TabGroupingButton`）・アーカイブ済み（`TabArchiveToggle`）・大きくする切り替え）→ タブの並び `.panel-tab-strip` → すぐ右に新しいタブ（チャット・ブラウザ・ターミナル。`PanelTabAdds`・`.panel-tab-adds`）→ 右端にペインの分割。
- タブが増えたら Chrome と同じくタブを細くして収める（ふだん 180px・いちばん細くて 36px）。タブ 1 つずつを入れ物（`container: panel-tab`。並びの幅を決めるときは `contain-intrinsic-inline-size` の 180px で数える）にして、細さに合わせて 130px 以下で添えたグループ名・96px 以下で表示中でないタブの閉じる・60px 以下で名前を隠し、表示中のタブは閉じるだけにする（マウスを乗せたタブは細くても閉じるを出し、60px 以下ではアイコンの代わりに閉じるだけ）。いちばん細くしても入らないときだけ並びを横にスクロールし、表示中のタブを見えるところへ動かす。
- タブとタブの境目には Chrome と同じ細い縦線（`.panel-tab + .panel-tab::before`。色は `--divider-strong`、表示中・乗せたタブの両側では消す）。表示中のタブは、明るい地・上と左右を同じ太さ（1px）で囲む色の枠・太字の名前で示し、まとまりの中では枠をまとまりの色にし、まとまりの下の線より上に重ねて線を切る（中身とつながって見える）。
- タブの列の何もないところの右クリックは、ボードの右のパネルだけボードツールバーの置き方のメニュー（`features/board/CLAUDE.md`）。

## タブのまとまり（`clusters/`）

- まとめ方（`TabGroupingButton`。「まとめない / グループ別 / 作業場所別」。見出しはサイドバーと同じ「チャットのまとめ方」）は欄ごとに覚える（`useTabGrouping(surface)` → `panelTabGrouping(surface)`。欄の中のペインでは共通。初めはまとめない）。まとめ方とアーカイブ済みの切り替えはチャットのタブにだけ効く。
- どのまとまりに入るかは `useTabClusters`（種類の表の `cluster` で決め、まとまりはサイドバー・ボードと同じ `bucketChats` の決め方・同じキー）: グループ別はチャットのグループ／新しいチャットは作成先のグループ（もうないグループのものはグループなし）、作業場所別はチャットの作業場所（`workplaceOf`）／新しいチャットは本体／ターミナルは開いたフォルダ、ブラウザ（グループ別ではターミナルも）は「その他」（`OTHER_CLUSTER`）。サイドバーと同じく、固定したチャットは「固定」（いちばん前）、アーカイブ済みは「アーカイブ済み」（後ろ。初めは畳む）に抜き出す。いくつかのプロジェクトのタブが並ぶときはプロジェクト名を前に添える。
- 並べるのは `clusterTabs`（`sortBuckets` と同じ順。まとまりの中はペインの並びのまま）。グループ別では、自分で作ったグループをサイドバーと同じ並び（グループの店）で、チャットのタブがなくても札を出す（`seeds`。グループを作る・名前を変える・並べ替える・消すとサーバーの知らせですぐ追従する）。札を出すのは一覧のペインだけで、分けたほかのペインは自分で置いたタブだけの列にし、タブのないグループの札・「チャット」の札を出さず、札の数はそのペインのタブの数（`useTabStrip` の `home`）。
- 見た目: まとまりを 1 つの枠 `.panel-tab-group` に入れ、まとまりの色の薄い地と下の線でどこまでが 1 つかを見せる（ブラウザのタブのグループと同じ）。色はプロジェクトの色と同じ 10 色（`PROJECT_HUES`）から、同じ列のまとまりどうしで被らないように決める（`clusterHues`。自分で作ったグループは覚えた色 `ChatGroup.hue` を先に取り、ほかはキーから決まる好みの色 `clusterHue`、使われていれば空いている色へ。10 色を使い切ったら被ってよい）。「その他」は色なし `.plain`。まとまりの枠も一緒に細くなり、どこまで細くできるかは見せているタブの数 `--cluster-tabs` から決める。札よりタブを先に細くする。
- 札（`TabClusterHead`）は 1 つの丸い札を左右に区切った形（`.panel-tab-cluster-pill`。色の地は札に付け、中の 2 つのボタンは透明で乗せた方だけ明るく）: 左 = 名前（押すと、まとまりのチャットをすべて作業中 → 回答待ち → 未読 → 既読 → アーカイブ済みに分けた一覧 `StateChatsPopover`（`chatsByState` の `all`）。行でそのチャットのタブを開く。一覧はタブの列に切り取られないよう画面に固定 `.cluster-chats-popover`。グループ別のまとまりの一覧には、いちばん下に「「グループ名」で新しいチャット」）、右 = まとまりのタブを畳む・開く（`.panel-tab-cluster-fold`。開いているときは「‹」、畳んでいるときはまとまりのタブの数 `tabCount`。表示中のタブを残しているかに関係なく同じ形）。名前は 2〜3 文字までは残し、中のタブを先に細くする。札は中身より細くしない（`grid` の `minmax(calc(2.5em + 14px), auto) auto` と `min-width: min-content`。中身より細く縮むと、右の「‹」がはみ出して隣のタブに隠れた）。札の角に、まとまりのチャットの状態ごとの数 `StateCornerCounts`（数えるのはタブで開いているチャットと、一覧のうち同じまとまりに入るもの。札が低いので丸を少し小さくし、数がある側は札の余白を広げて名前に重ねない）。チャットの数（サイドバーの見出しと同じ数え方。表示だけ消したタブも数え、下書きは数えない）は名前の説明に出す。「その他」は押せない。
- 畳んだまとまりは、そのペインで表示中のタブだけを残す（`visibleClusterTabs`。隠したチャットを一覧から開けば表示中になって出る。見た目の並び `display` にも入れない）。隠れたタブだけになったまとまりは薄い地と下の線を消して札だけにする（表示中のタブを残しているときは残す）。開閉は `useFolds("panel", …)`（すべてのパネル・ペインで共通）。札の右クリックの「タブを畳む / 表示する」も同じ。
- 札の右クリック（プロジェクトの分かるまとまりだけ）: 「「グループ名」で新しいチャット」（グループ別のとき。作成先をそのグループに）・「新しいグループを作成…」（`promptDialog` → `api.createGroup`）、自分で作ったグループの札では区切り線の下に「「グループ名」を削除…」（サイドバーと同じ `confirmDeleteGroup` で確かめてから。中のチャットはグループなしに戻る）。
- 自分で作ったグループの札はつかんでドラッグし、同じプロジェクトのほかのグループの枠に落とすと並びを入れ替える（`useClusterReorder`。サイドバーと同じ `useReorder` で、入る位置に縦の線・動かしているまとまりは薄く。`api.reorderGroups` で DB の並びを変えるので、サイドバー・グループのボード・ほかのパネルの札も同じ並びになる。グループなし・作業場所・その他・ほかのプロジェクトのグループには落とせない）。
- まとめないときも、タブの列の左端（横にスクロールしても動かない位置）に同じ札「チャット」（`TabClusterHead` の `all`。控えめな地 `.panel-tab-cluster.all`、タブの数は出さない）を置き、パネルのチャット全体の状態ごとの数と一覧を出す。チャットが 1 つもなければ出さない。
- ドラッグで落とす位置は見た目の並びで印を付け、`paneIndexOf` でペインの並びの位置に直して移す（`useTabDrag` の `toPaneIndex`）。

## 下書き（送る前の新しいチャット）

- 下書き（`panelDrafts.ts` の `PanelDraft`）は、どの欄のどのタブか・作成先・書きかけの文・表示しているか。すべての欄の分はサイドバーの各プロジェクト（`DraftRows`）・⌘⇧A のいちばん上（`useAllDrafts`）、ボードの分（そのボードのパネルと同じプロジェクトのチャット欄）はボードの「下書き」の列（`usePanelDrafts`）に出す。押すとその欄で開き、画面に出ていない欄のものは、その画面へ移ってから開く（`openDraft`。`panelScreen`）。消すのは `discardDraft`、作成先のグループを変えるのは `setDraftGroup`（サイドバーでグループへドラッグしたとき。欄が画面にあればそのタブを、なければ覚えている内容を書き換える）。
- 書いている途中の文は `Composer` の `onTextChange` からタブの `draftText` に入れ、カードに初めの 3 行を出す。
- 下書きのタブだけは再起動しても消えないよう、`draftPersistence.ts` で localStorage（`NEW_CHAT_DRAFTS`。パネルごとのタブの JSON）にも残し、起動したら閉じた欄のタブとして戻す。書きかけの文は `NewChatPane` が入力欄に 1 回だけ戻し、隠れているタブではピントを移さない（`fill` の `focus: false`）。送った・閉じたら消え、消したプロジェクトの分は App が `forgetDraftsOfMissingProjects` で片付ける。添付は残さない。

## 欄の殻

- ボードの右のパネル（`useBoardPanel`）: 新しいチャットは、プロジェクトのボードならそのプロジェクト、全プロジェクトのボードなら選べるプロジェクトの先頭で始める（パネルでバッジから選び直せる）。カードから開いた・新しいチャットを送ったチャットを URL にもし（サイドバーで強調され、戻る・進むで行き来できる）、サイドバー・検索などから開いたチャット（URL）をパネルで開く（`features/board/useBoardFocus.ts`）。開閉のボタンはボードのツールバーの右端の `PanelToggle`（閉じていて開いたタブがあれば数を出す）。
- 幅（`usePanelWidth`。左端のつまみで変えて覚える `PANEL_WIDTH`）: パネルは外枠・角の丸み・影を付けず、ボードとの境目に左の 1 本線だけを引き、開いているときは画面の右・下の余白まで伸ばして端に付ける。開閉ではタブの列と中身を開き終えたときの幅 `--panel-shown` のまま左端にそろえ、パネルの枠で切り取って右から滑り込ませる（動いている間に中身を並べ直さない。切り取りはパネル自身で行い、`.board-body` に `overflow-x: clip` を付けない）。横に残るボードが狭すぎる（`MIN_BOARD_WIDTH`（200px）未満）ならボードを覆う（`covering`）。横幅いっぱいの切り替え（`PANEL_MAXIMIZED`）は覆っているときも隠さず「元の幅に戻す」として出し、押すとボードが残る幅（`fitWidth`）まで縮める。それでもパネルの最小の幅に足りないほど狭ければ押せなくする（`canRestore`）。覆っている・横幅いっぱいのときは `.board-body.panel-full` で見えないボードとの間隔も消す（列の指定はふだんと同じ形のままパネルの幅だけを 100% にする。形を変えると、ブラウザが間をなめらかにつながない）。横幅いっぱいを切り替えて幅が動いている間（`stretching`）は、右端は動かず左端だけが伸び縮みするので、中身を枠の幅に合わせて並べ直す。左端のつまみのドラッグ中は判定で張り付けず指の位置どおりの幅にし、離したときにボードが狭すぎれば覆う。
- チャット欄（`useProjectChat` ＋ `ProjectChat`）: 画面の右端の、どのタブでも開ける欄（ボードの右のパネルとは別のもの）。App のレイアウトの 3 列目に置き、下のパネルより下まで伸ばす。開閉は右上のレイアウトの開閉（`app/LayoutToggles`）か ⌥⌘B。開閉はプロジェクトごと、幅はアプリ全体（`PROJECT_CHAT_WIDTH`）。真ん中に `--main-min-w` を残すところまでしか広げない（`--chat-shown`）。閉じても要素は残し（幅 0）、書きかけの文をなくさない。幅が狭いので、タブの列は 2 段にする: 上の段（信号機ボタン・右上のレイアウトの開閉と同じ行）にタブ、下の段に道具（DOM は変えず `project-chat.css` の `order` と幅いっぱいの `::before` で折り返し、分けたペインのタブの列の高さ `--split-tabs-h` も 2 段分にする）。
- 下のパネル（`useBottomPanel` ＋ `BottomPanel`。VS Code の「パネル」と同じ）: どの画面でも ⌃\` / ⌘J で開閉（ターミナルの中で押しても効くよう、ほかより先に受け取る）。高さは上の端のつまみのドラッグ（`BOTTOM_PANEL_HEIGHT`）、最大化と閉じるはタブの列の道具。タブ・開いているかはプロジェクトごと（全プロジェクトの画面は別）。Esc では閉じない。見せている最後のタブを閉じると閉じる（閉じたら最大化もやめる）。閉じても要素は残し（高さ 0）、シェルはメインプロセスで動き続ける。フッターにピントがあるときの ⌘\ で右に分ける。開閉は右上の `LayoutToggles`（下の帯には置かない）。
- 欄の開閉の動きは `--panel-motion-duration` / `--panel-motion-ease` にそろえる（`styles/CLAUDE.md`）。
