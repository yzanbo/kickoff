# 左のサイドバー（`features/sidebar`）

上に新しいチャット・全プロジェクト・自分待ち・検索、その下にプロジェクトごとのチャット一覧、左下に設定。グループの操作の共通部分（`features/group/`）もここに書く。まとめ方・数え方・開閉の仕組みは `features/chatList/CLAUDE.md`、プロジェクトの印・メニュー・並び・タグは `features/project/CLAUDE.md`。

- 開閉（⌘B）と幅（右端のドラッグ、ダブルクリックで既定に戻す。200〜480px）は `useSidebar` ＋ `Sidebar`。閉じているときの「開く」ボタン `SidebarOpenButton` は、Electron のドラッグ領域より優先されるよう画面のいちばん後ろに置く。
- プロジェクトの並びの状態と操作は `useProjectNav`（並べ方・並び順・しまったものを出すか・自分待ちだけ・検索・いま選んでいるプロジェクト（`saveCurrentProject`。⌘N・全プロジェクトのボードの「新規」の作成先と、全プロジェクトの画面のチャット欄の持ち主にも使う。読むのは `currentProject.ts` の `useFallbackProject`（もうなければ先頭））と切り替え・ショートカット・スワイプ・すべて閉じる / 開く）、表示は `ProjectNav`（縦並び `ProjectStack` / スライド `ProjectSlides`）。1 プロジェクトのページは `WorkspacePage`（中身の変わらないページは描き直さない）、その行の絞り込みと分け方は `useWorkspaceRows`（段の決め方 `sidebarLevels` は `sidebarChatOrder.ts`。同じ分け方でチャットの並びだけを返す `useSidebarChatOrder` を、パネルの一覧のペインのチャットのタブの並びにも使う）。

## 一覧の上の見出し（`ProjectListHead`）

- 何に効くかで行を分け、設定の種類（ジャンル）ごとのボタンを並べる（1 つのボタンには 1 種類だけ。種類の違う設定を 1 つのボタンにまとめない）。3 つ以上あるものはメニューから選ぶ `HeadMenu`（`ChoiceMenu` を開く）、2 択は押すたびに切り替える `HeadToggle`。どちらも 2 段で、上に種類の名前・下にいまの値。幅は取りうる値 `values` のいちばん長いものに固定し、選び直しても変わらない。文字では横幅に入らないときは文字を隠して、いまの値を表すアイコンだけにする（`hooks/useOverflowCompact` が、中身の幅に少しのゆとり（16px）を足して入るかで決めて `.icon-only` を付ける。文字が枠にぴったり付くと窮屈に見えるため。決め打ちの幅で切り替えていたときは、ボタンの名前や数が変わると切り替わる前に右端が見切れた）。
  - 1 行目「プロジェクト」: 並べ方（縦並び `stack` / 横スライド `slide` / 縦スライド `rail`。`SIDEBAR_LAYOUT`。初めは縦スライド）・並び順（手動 / 最近動いた順。`SIDEBAR_PROJECT_ORDER`。初めは最近動いた順。最近動いた順のときもドラッグで並べ替えられ、落とすと手動に切り替わる）・表示（カードを 1 行 / 2 行。初めは 2 行）・アーカイブ（しまったプロジェクトを出すか `SIDEBAR_SHOW_ARCHIVED_PROJECTS`。初めは閉じる。縦並びでは一覧の下の見出しでも切り替える）。
  - 2 行目「チャット」: まとめ方（まとめない / グループ別 / 作業場所別。メニューの見出しは「チャットのまとめ方」、名前は右のパネルのタブのまとめ方と同じ `CHAT_GROUPING_LABELS`。初めはまとめない。メニューの下に「まとまりを色付きで表示」（`HeadMenu` の `extra`。選んでも閉じない））・並び順（最近順 / 状態順 / 手動。3 つなのでメニュー `HeadMenu`。メニューでは「最近動いた順」「手動（ドラッグで並べた順）」。パネルのタブの列の「表示」のメニューの「チャットの並び順」と同じ設定）・表示（行を 1 行 / 2 行。初めは 1 行）・アーカイブ（出すか。初めは隠す）。名前のすぐ右に、並べ方にかかわらず小さなアイコンのボタンで「すべて閉じる / 開く」（`.project-list-fold`。すべてのプロジェクトと中のまとまり。`foldAll("sidebar", …)`）。
  - アーカイブはどちらの行も右端。「表示」はプロジェクトのカードとチャットの行で別々に切り替え、1 つの設定で両方を変えない。
  - 「自分待ち」の行（自分待ちがオンのときだけ）: オンのときの表示を、出し方（自分待ちだけ / 一覧の上に / プロジェクト内。3 つなのでメニュー `HeadMenu`）と並べ方（プロジェクト別 ⇔ 状態順。`HeadToggle`）で選ぶ（`WaitingRow`。ほかの行と同じく 1 つのボタンに 1 種類。ボタンが 2 つだけなので、それぞれ 2 列分の幅に置き、長い名前でも上の行の列を広げない。ボタンの名前は短く、メニューと説明で「プロジェクト内の上にまとめる」のように言う）。プロジェクト内では並べ方はプロジェクト別だけなので、並べ方のボタンを押せなくする（`canChooseOrder`。隠さず薄くする）。名前とアイコンは `waitingView.ts` の `WAITING_SCOPE_META` / `WAITING_ORDER_META`。上の行の「自分待ち」の右クリックでも、同じ 2 つのまとまりで選べる（`WaitingViewMenu`。選ぶとオンにする）。
  - いちばん下の「タグ」の行（`TagFilterRow`。タグがあるときだけ）: 使っているタグと「タグなし」の小さなボタンを折り返して並べ、押すたびに絞り込みを付け外しする（複数選べ、選んだタグのどれかが付いているプロジェクトだけを出す。選んでいるものはアクセントの色、× で外す）。1・2 行目のボタンを増やさないため（増やすと既定の幅でも文字が隠れる）。
- すべてのプロジェクトに効く設定は、プロジェクトのメニューに入れずこの見出しに置く。下の行は主な操作だけ（縦並びは新しいプロジェクト、スライドはプロジェクトの丸）で、表示方法の操作を足さない。
- 上の行の「自分待ち」（`SIDEBAR_WAITING_ONLY`）は、回答待ち・未読のチャットに目を向ける切り替え（初めはオン。数はしまったプロジェクトを除く `waitingChats`）。オンのときの表示は、出し方 × 並べ方の 5 通り（保存は 1 つの値 `SIDEBAR_WAITING_VIEW`。軸との行き来は純粋関数の `waitingAxes.ts`。今までの値はそのままの意味で読む）:
  - 自分待ちだけ × プロジェクト別（`filter`）: 待っているチャットのあるプロジェクトだけを、その中の待っているチャットだけで並べる（下書きのあるプロジェクトも並べる）。
  - 自分待ちだけ × 状態順（`list`）: プロジェクトの一覧の代わりに、待っているチャットだけをプロジェクトをまたいで並べる（`WaitingInbox` の `list`）。
  - 一覧の上に × 状態順（`inbox`）/ × プロジェクト別（`inbox-project`。初め）: 一覧のいちばん上に「自分待ち n 件」のまとまり（`WaitingInbox` の `top`。開閉を覚える）を置き、その下はオフのときと同じすべての一覧。スライドではスライドの上に置き、高さの上限を付けて中でスクロールする。
  - プロジェクト内（`in-project`。並べ方はプロジェクト別だけ）: 各プロジェクトの中のいちばん上（下書き・固定より上）に「自分待ち n」のまとまり（`WorkspacePage`。中は状態順。開閉はプロジェクトごとに覚える）を置き、その下はいつもの一覧（待っているチャットは両方に出す。一覧の上にと同じ）。検索・状態で絞っている間は出さない。
  - 言い方の決まり: 「〜順」は並べる順、「〜別」は見出しに分ける（チャットの並び順の「最近順 / 状態順」・まとめ方の「グループ別 / 作業場所別」と同じ）。
  - 状態順は、状態の見出し（回答待ち → 失敗 → 未読）に分け、見出しの中は待っている時間の長い順（回答待ちはいちばん古い依頼が届いた時刻、ほかは最後に動いた時刻。純粋関数の `inboxOrder.ts` の `inboxSections` / `waitingSince`）。プロジェクト別のまとまりは、サイドバーのプロジェクトの並びでプロジェクトの見出し（印と名前・件数。開閉を覚える）に分け、中は状態順（`inboxByProject`）。行はプロジェクトの一覧と同じ `ChatRow` で、状態順のときはどのプロジェクトかの印（`project`）を添える。出すのは、しまっていない・タグの絞り込みに合うプロジェクトのチャット。プロジェクトとチャットの行を絞るのは「自分待ちだけ × プロジェクト別」のときだけ（`useProjectNav` の `filterByWaiting`・`useWorkspaceRows`）。画面ではなく一覧の絞り込みなので、オンは開いている画面の印（「全プロジェクト」の `.active` の背景）と分け、背景を付けずにアクセントの色（`--accent-fg`）と「オン」の札で示す（`.nav-row.on`・`.nav-row-state`）。「自分待ちだけ × プロジェクト別」で自分待ちがない・タグで絞って合うプロジェクトがないときは、その旨と戻すボタンを出す（下書きは数に入れない `hasWaiting`）。プロジェクトが 1 つもないときは、自分待ちかどうかに関係なく、ここに何が並ぶかの一言と「新しいプロジェクト」（`.workspace-empty`）。

## 並べ方とプロジェクトの切り替え

- 縦並びは見出し・すべてのプロジェクトをまたぐ検索欄（チャット名で絞り、一致するプロジェクトだけを開いて並べる。プロジェクトの検索欄が空のときに効く）・プロジェクトのカードの列。固定したプロジェクトがあれば「固定」「プロジェクト」の見出し（`.project-section-label`）で分ける。カードを 1 行で表示のときは、チャット数とタグの行を出さない。
- スライドは 1 ページ = 1 プロジェクト。横スライドは丸の列（`WorkspaceDots`）を下に並べて横にスワイプ、縦スライドは丸を左に縦に並べて縦にスワイプ（`useWorkspaceSwipe` の `axis: "y"`。一覧がその向きにスクロールできる間・スクロールの慣性では切り替えず、端まで来てからのスワイプだけ。指に追従させる間は React の再描画を挟まず transform を直接動かす）。丸の帯の上のスワイプでも切り替える（`stripHandlers`。横スライドは横方向だけ、縦スライドは縦・横どちらでも）。固定したプロジェクトがあれば丸の列に区切りを入れる。丸の角には状態ごとのチャット数 `StateCornerCounts`。
- ショートカット: どの並べ方でも ⌥⌘← / → と ⌃Tab / ⌃⇧Tab で前後へ（⌃Tab は端で反対の端へ回る）、⌃1〜9 で n 番目。縦スライドは ⌥⌘↑ / ↓ でも前後へ（チャットにピントがあるときは、チャットの前後の指示へ移るのが先。`defaultPrevented` なら見ない）。どれもタグの絞り込みのあとの並び。
- プロジェクトの並べ替えのドラッグは `useProjectReorder`（縦並びのカード・横スライドと縦スライドの丸・全プロジェクトのボードのプロジェクトの段の見出しで共通。しまっていないプロジェクトだけ。ドラッグはタグで隠れたものを含む並び全体の中で動かす）。並び順が最近動いた順でもつかめ、落とすと、いま見えている並びのまま動かしたものだけを動かした順を手動の並びとして保存し（`api.reorderProjects`）、並び順を手動に切り替える（`onManual`）。入る位置の線は、横に並ぶ横スライドの丸では縦線、縦に並ぶ縦スライドの丸・縦並びのカードでは横線（`sidebar-list.css`。利用者の依頼で、前は縦スライドの丸でも縦線だった）。利用者の依頼で、前は手動の並びのときだけつかめ、初めの最近動いた順ではドラッグしても何も起きなかった。

## プロジェクトの見出し（`WorkspaceHead`）

- どのプロジェクトを見ているかが一目でわかるカード（印 `ProjectMark` ＋ 名前 ＋ プロジェクトの色の薄い地。開閉の矢印は灰色）。常に出すのは、いつも使うものだけ: 開閉（左の矢印）・名前・状態ごとのチャット数 `HeadCounts`（作業中・回答待ち・未読。色はカンバンの列と同じ。押すとそのプロジェクトのチャットをその状態だけに絞り、もう一度押すと戻す）・新しいチャット（ほかの新しいチャットのボタンと同じペンのアイコン）・固定の印。固定のボタンはいつも出し、固定しているかは色と塗りで分ける。しまったプロジェクトは、ピンの代わりに戻すボタン。名前の下の 2 行目にチャット数とタグ（`ProjectTags`）。
- 押し方はサイドバー全体で同じ: 左の矢印（名前より左のどこでも。`pressedLeftOfName`）は開閉だけ。それ以外を押すと、選んでいて開いていれば閉じ、それ以外（選んでいない・選んでいて閉じている）は選び直して開く（プロジェクトはカンバン）。自分で作ったグループの見出しは、どこを押しても開閉だけ（利用者の依頼で、プロジェクトのボードの列の分け方とグループのボードの画面をなくしたので、前の「そのグループのボードを開いてハイライトする」はやめた）。
- マウスを乗せたときだけ出す操作は作らない。ほかの操作は右クリックの `useProjectMenu`（`features/project/CLAUDE.md`）。操作を足すときは、まずこのメニューに入れ、常に出すかは別に考える。
- 開閉の矢印（`GroupToggle`。プロジェクトの開閉も同じ灰色の矢印）は、行を押しても開閉するのでボタンらしい背景を付けず、乗せたら色を濃くするだけ。アイコンは矢印の横に添える。
- 開閉は `Collapse` で高さをなめらかに変える（プロジェクト・グループ・グループなし・並べ方のまとまり・固定・アーカイブ済み。段下げと縦の線は `indent`）。枠の線は出さない。

## チャットの行とまとまり

- まとめ方と並び順は `useChatLayout`（`chatGroupings.ts`。まとめ方 = まとめない / グループ別 / 作業場所別、並び順 = 最近順 / 状態順 / 手動。すべてのプロジェクトに効く。初めはまとめない × 最近順）。分けるのは `bucketChats`。
  - 手動（利用者の依頼）: まとまり（自分で作ったグループ・No Group・作業場所・固定・アーカイブ済み。まとめないときは一覧）の中を、ドラッグで並べた順（`Chat.position`。`features/chatList/manualOrder.ts` の `byManual`。まだ並べていない新しいチャットはいちばん上に新しい順）にする。チャットの行を同じまとまりの行の上半分・下半分へドラッグすると、その前・後ろに線を出して動かす（`useChatRowReorder`。行の `ChatRow` の `reorder`）。並べられるのは同じまとまりのチャットどうしだけ（`bucketScopes`。ほかのまとまり・プロジェクトへのドラッグは、いつものグループへ移す・プロジェクトへ移すの落とし先）。最近順・状態順のときもドラッグでき、落とすと、いま見えている並びのまま動かしたものだけを動かした並びを保存して（`sidebarChatOrder.ts` の `useManualChatReorder` → `api.reorderChats`。プロジェクトの中の 1 本の並びなので、まとめ方を変えても順が保たれる）、並び順を手動に切り替える（プロジェクトの並べ替えと同じ）。パネルの一覧のペインのチャットのタブもこの並びで並び、タブのドラッグでも同じ並びを変える（`features/panel/CLAUDE.md` の「サイドバーとの連動」）。
  - グループの見出しは「グループ別」のときだけ出す（ほかのまとめ方ではグループに関係なくプロジェクトのチャットすべてを並べる）。グループを作り始めたら「グループ別」に切り替える。
  - 固定したチャット（`togglePinChat`。並び順の時刻は変えない）はプロジェクトのいちばん上の「固定」（ピンをプロジェクトの色で塗る `.row-section.pinned`）に抜き出す。アーカイブ済み（出しているとき）は、まとめないときはいちばん下の「アーカイブ済み」にまとめ、グループ別・作業場所別のときは、まとまり（自分で作ったグループ・No Group・作業場所）ごとの中身のいちばん下に、そのまとまりのアーカイブ済み（`ArchivedBucketFold`。初めは閉じる。開閉はまとまりのキー ＋ `/archived`。`bucketChats` の `archived: "nested"` の `bucket.archived`。アーカイブ済みだけのまとまりも出す）を置く（どちらも `FoldSection` の `look="row"`。利用者の依頼で、前はグループ別でもいちばん下にまとめていた）。
  - まとまりの色（`bucketColor.tsx` の `useSidebarBucketColors`）: 「まとまりを色付きで表示」（`SIDEBAR_BUCKET_COLORS`。初めは色付き。前は初めは色なしだったが、利用者の依頼で初めから付ける。自分で切り替えた人の選択はそのまま）のとき、グループ別・作業場所別の見出し（自分で作ったグループ・No Group・作業場所・固定・アーカイブ済み）のアイコン（フォルダ・ブランチ・ピン・アーカイブ）と名前を、タブの列のまとまりの札と同じ色にする（`huedHeadProps` → `.bucket-hued` と `--group-hue`。色は `features/chatList/CLAUDE.md` の「まとまりの色」。中の段（状態）には付けない）。切り替えはまとめ方のメニューと、見出しの右クリック（自分で作ったグループはグループのメニューの下に足す `useGroupMenu` の `extra`、ほかの見出しはこの項目だけのメニュー。まとめないときは出さない）。
  - 見出しに分けた表示は `GroupedChatRows`（作業場所 × 状態順は、作業場所の見出しの中をさらに状態ごとに分ける。グループなし・自分で作ったグループの中・アーカイブ済みの中で同じように使う。作業場所別のまとまりのアーカイブ済みは `renderArchived` で中身のいちばん下に描く）。まとまりごとに開閉し（`useFold("sidebar", まとまりのキー)`）、検索中はすべて開く。
- 行（`ChatRow`）: 押すと右のパネルで開く・⌘ / Shift を押しながらで複数選ぶ・ダブルクリックで名前を変える・ドラッグでグループへ移す（`startChatDrag`）・同じまとまりの中でドラッグして並べ替える（手動の並び。上の「手動」）・「アーカイブ済み」へドラッグしてアーカイブする / アーカイブ済みの行を一覧へドラッグして戻す（どちらも右クリックの「アーカイブ」「アーカイブから戻す」と同じ確認のダイアログを出してから `toggleArchiveChat`。`ArchivedBucketFold.tsx` の `archiveDroppedChat` / `restoreDroppedChat`。作業中のチャットはサーバーが断るので、その理由をお知らせで出す。グループ別では、グループの中の「アーカイブ済み」へ落とすとそのグループへも移し、アーカイブ済みの行をグループ・No Group へ落とすと、戻してそのグループへ移す（`useGroupDrop` の `onRestoreChat`）。グループの見出しを出していないときは、見出しの下の一覧（`.restore-drop`）へ落とすと戻す（`useSidebarArchiveDrops`）。落とし先は、ドラッグしているチャットを見て受けるものだけを枠で示す（アーカイブ済みの落とし先はアーカイブしていないチャットだけ、戻す落とし先はアーカイブ済みだけ。dragover ## 自分で作ったグループ（`CustomGroupSection`・`features/group/`）

- 見出しは `FoldHead` の `look="group"`（フォルダのアイコン付きの `GroupToggle` で開閉、見出しのほかの部分を押しても開閉する）。名前のダブルクリックで名前を変える・ドラッグで並べ替える・チャットをドロップしてグループへ移す・右クリックと「…」でメニュー（名前を変更・削除。`useGroupMenu`。「…」はいつも出す）。チャットのないグループは、開いていても中に何も出さない（前は「チャットをここへドラッグ」を出していたが、利用者の依頼でやめた。落とし先は見出しを含むまとまり全体のまま）。見出しに渡す束（メニュー・名前の変更・ドロップ・ドラッグ）は `useGroupSections` の `sectionProps(group)`。
- 「No Group」の見出し（`UngroupedHead`）はグループがあるときだけ出す（チャットを落とすとグループから外す。落とし先は見出しと中身を包む `.custom-group` の要素で、`useGroupSections` の `ungrouped`）。グループの見出しと同じく、見出しのドラッグでグループの間へ並べ替える（位置 `ungroupedAt` = 前にあるグループの数は、全プロジェクトのボードのグループの列と同じ設定 `groupBoardUngroupedAt` にプロジェクトごとに覚える。覚えていなければいちばん下。出すグループの前後への分け方は `features/group/groupOrder.ts` の `splitAtUngrouped`（絞り込みで一部のグループだけを出していても、もとの並びの中の位置で分ける））。グループに下書きがあるときも出す（戻すドロップ先）。
- 共通の部分は `features/group/groups.ts`: 並べ替えのドラッグ `useReorder`（グループ・プロジェクト・タブのまとまりの札で共通。動かしているものを薄くし、入る位置に線）・ドロップ先 `useGroupDrop`（サイドバーと全プロジェクトのボードのグループの列で共通。チャットはそのグループへ、グループの見出しはその位置へ、`onMoveDraft` があれば下書きの作成先も変える。ほかのプロジェクト（`projectId` と違う）のチャットは `onForeignChat` があるときだけ受け、なければ外側の落とし先へ渡す。`ungroupedAt` を渡すと「No Group」も並べ替えの並びに入れる（全プロジェクトのボードのグループの列・サイドバー。ID は `UNGROUPED_SORT_ID`））・ドラッグの開始 `startChatDrag` / `startDraftDrag`（独自の MIME 型。どちらも、`useReorder` の `handle` も、ドラッグの絵の共通の写し `startDragGhost` を通し、動かしている物を薄くする state はその `after` で変える）・グループ以外のチャットの落とし先 `useChatDropTarget`（アーカイブ済み。`passThrough` のチャットは外側へ渡す）・いくつもの落とし先を 1 つの hook で持つ `useChatDropTargets`（スライドの丸。どちらも `accepts` / `passThrough` / `blockedBy` の決まりを渡す）とドラッグ中か `useChatDragging`・削除の確かめ `confirmDeleteGroup`（中のチャットは消えず、グループなしに戻る）・グループを選ぶメニュー `GroupPickMenu`（新しいチャットの作成先・まとめて選んだチャットの移動先）。

## 下書き（`DraftRows`）

すべてのボード・チャット欄の下書き（送る前の新しいチャット）を、サイドバーの各プロジェクトにも出す（`useProjectDrafts`。仕組みは `features/panel/CLAUDE.md`）。名前は、最初のチャットを送るまで「New Chat」のまま（タブと同じ。利用者の依頼で、書きかけの文の 1 行目を出すのをやめた）。いまの画面のプロジェクトのチャットのパネル（チャットタブ・ボードの右のパネル）でその下書きのタブを表示しているときは、チャットの行と同じく選択中に見せる（`useDraftSelected`。チャットの行はタブで選ぶと URL になって選択中になる。`features/panel/CLAUDE.md` の「欄の殻」）。押すとそのパネルで開き（別の画面のものはその画面へ移ってから）、右クリックで開く・ピン留め・削除。ドラッグでグループ・グループなしへ落とすと作成先のグループを変える。ピン留めした下書き（タブの `pinned`。`togglePinDraft`。再起動しても残る）は、まとめ方にかかわらずプロジェクトのいちばん上の「固定」の中（固定したチャットの上。数にも入れる）に抜き出し、グループの中・いちばん上には出さない（`useWorkspaceRows` の `pinnedDrafts`）。送ると、できたチャットも固定する（`PanelTabPage`）。グループの下書きはそのグループの中に、グループなし・もうないグループのものは、グループの見出しを出しているときは「No Group」の中（チャットの上。`ungroupedDrafts`）、見出しがないときはいちばん上に並べる。並び順が手動のときは、まとまりのいちばん上ではなく、タブの列（その欄の一覧のペイン）での下書きのタブの位置に合わせて、チャットの行の間に置く（利用者の依頼。`useDraftPlacement`: タブの列で下書きより前に見える同じまとまり（グループ・見出しの下の一覧。作業場所別なら同じ作業場所）のチャットのすぐ後ろ。純粋関数は `manualOrder.ts` の `draftAnchor`、タブの位置は `panelDrafts.ts` の `draftTabSpot`。前に同じまとまりのチャットのタブがなければ、いままでどおりいちばん上。「自分待ち」のまとまりには出さない）。行の字下げは、同じまとまりのチャットの行とそろえる（グループの中のチャットの行だけに残っていた 10px の余白を消し、下書き・No Group・状態ごとの段と同じ位置にした）。下書きのあるグループは絞り込み中（自分待ち）も隠さない。検索・状態での絞り込み中は出さない。
