# ボード（`features/board`）

チャットのカンバン（プロジェクトのボード `KanbanBoard` と、全プロジェクトの画面 `AllProjectsPage` の `AllProjectsKanban`。中身は共通の `KanbanView`。プロジェクトがないときは `NoProjectsWelcome`、タグの絞り込みに合うものがないときは `EmptyState` と「絞り込みを外す」。`features/project/CLAUDE.md`）と、自分で作ったグループの列のボード（`GroupBoard`）。列・段・リストのまとまりは `bucketChats`（`features/chatList/CLAUDE.md`）、右のパネルは `features/panel/CLAUDE.md`。

## 列の分け方と表示

- チャットを開く先は設定の「チャットを開く場所」で決まる: チャットタブ（初め。カードを押すとプロジェクトの「チャット」タブへ移って開く。ボードに右のパネルを置かない）/ ボードの右のパネル。ボードは `BoardChats`（`features/panel/CLAUDE.md` の「欄の殻」）だけを見て開き、`KanbanBoard` / `GroupBoard` が置き方で中身の部品（パネルあり / なし）を選ぶ。
- グループは「ボード」の中の列の分け方の切り替え（`BoardColumnsToggle`。状態 = カンバン `#/projects/:id` / グループ = グループのボード `#/projects/:id/groups`）。最後に見た方を `PROJECT_BOARD_COLUMNS` に覚え、ボードのタブ・チャットの URL はそちらで開く（`app/router.ts` の `boardTabOf`）。サイドバーのグループからは、グループの列で開く。
- カンバンの列（作業中・回答待ち・未読・既読）は AI の状態から `boardColumnOf` で決め、人は動かさない。カードの点はより細かい状態（`STATE_TONE`）。
- 表示はボード / リストの 2 つ（`useBoardView` の `view`。`BOARD_VIEW`）で、どちらも見出しの「段: 分けない / グループ / 作業場所 / プロジェクト」（`LaneSelect`）で段（スイムレーン）に分けられる（`split`。`BOARD_SPLIT`。表示を切り替えても段に分けたまま）。表示と段に分けるかはカンバン・グループのボードで共通。
- 段の分け方（`useKanbanLanes`。ボードとリストで共通）: 作業場所（ブランチ）・グループ（プロジェクトのボード）・プロジェクト（全プロジェクトのボード）。プロジェクトのボードは `PROJECT_BOARD_LANES`（初めは作業場所）、全プロジェクトのボードは `ALL_PROJECTS_BOARD_LANES` に別に覚える（初めはプロジェクト = プロジェクト別のカンバン）。作業場所の段にプロジェクト名を添えるのは、いくつかのプロジェクトが並ぶ全プロジェクトのボードだけ。
- 段（`BoardLanes`）は見出しで開閉し（`useFolds(foldPlace, …)`。`foldPlace` はボードごとの `board:<パネルのキー>` / `board:groups:<プロジェクト>`）、段ごとに、ボードと同じくいちばん左に下書き（その段に入る作成先のもの。下書きだけの段も出す）、続けて状態の列を並べる（`StateColumns`）。リストを段に分けたときは、段の中に下書き → 状態ごと → アーカイブ済みを縦に並べる（`ListSections`）。
- リスト表示のときは、表示の切り替えのすぐ後ろに「リストの行」の切り替え（2 行 = 名前の下に作業場所・状態 / 1 行 = 名前の後ろに並べ、狭ければ名前から省く。`useBoardListCompact`（`BOARD_LIST_COMPACT`。すべてのボードで共通。初めは 2 行）で、行は `useBoardCards` の `row` が `.list-row.compact` にする）。
- グループのボードの段はグループだけで、段に分けると列は下書き＋状態。段へカードをドラッグするとグループを移す。リストはもともとグループごとのまとまりなので「段:」を出さない。

## 全プロジェクトのボード（`AllProjectsKanban`）

全プロジェクトの画面ではチャットを開かず、そのプロジェクトへ移って開く（サイドバー・⌘⇧A・検索と同じ。全プロジェクトとプロジェクトの 2 つのパネルで、同じチャットが別々のタブ・分割で開いて「さっきのタブはどこ？」とならないように。全プロジェクトの画面は見渡す所、作業はプロジェクトで）。

- 右のパネルを持たない（`BoardShell` に `rightPanel` を渡さない。ツールバーのパネルの開閉も出さない）。
- カード・リストの行・右クリックの「開く」は `openChat` でそのプロジェクトのボードへ移り、そのパネルで開く。確かめのダイアログは出さない（戻るのはサイドバーの「全プロジェクト」1 回で、取り消せない操作ではないため）。代わりに、乗せると「プロジェクト「○○」で開く（そのプロジェクトの画面へ移ります）」（`useBoardCards` の `openTitle`）。
- ツールバーの「新規」は ⌘N と同じく、サイドバーで選んでいるプロジェクト（`useFallbackProject`。もうなければ先頭）へ移って新しいチャットを始める（乗せるとどのプロジェクトか）。
- 「下書き」の列には、すべての欄の下書き（`useAllDrafts`。出しているプロジェクトのもの）をプロジェクトのバッジ付きで並べ（`DraftCards` の `showProject`）、押すとその欄の画面へ移って開く（`openDraft`）。以前の全プロジェクトのパネルに残っていた下書きは、起動したときに作成先のプロジェクトのパネルへ移す（`features/panel/CLAUDE.md`）。
- 段・アーカイブ済みのまとまりの開閉を覚える場所は、パネルがあったときと同じ `board:kanban:all` のまま（覚えた開閉を消さない）。
- 列の分け方を「状態 / グループ / 分けない」で切り替えられる（`AllProjectsColumnsToggle`。プロジェクトのボードの「状態 / グループ」と同じ、表示のまとまりのボード / リストの後ろ。`ALL_PROJECTS_BOARD_COLUMNS` に覚える）。
- グループのときは、いつもプロジェクトの段に分け（`by: "project"`。チャットのないプロジェクトの段も出す。段の分け方の選択は出さない）、段の中にそのプロジェクトのグループの列（`ProjectGroupColumns`。部品と操作はプロジェクトのグループのボードと同じ `GroupSections` / `useGroupBoard`。「グループを作成」・名前の変更・削除・見出しのドラッグでの並べ替えも同じ）を並べる。カードはドラッグでき（`useBoardCards` の `drag`）、列へ落とすとそのグループへ移す。ほかのプロジェクトのグループへ落とすと、確かめてからそのプロジェクトへ移してそのグループに入れる（`useGroupDrop` の `onForeignChat`。作業中なら落とせない）。列の＋はそのプロジェクトへ移ってそのグループで新しいチャットを始める（`openNewChat`）。絞り込み（名前・アーカイブ・作業場所）は全プロジェクトのボードのものを使い、見出しの名前は「グループ」になる。利用者の依頼。
- 分けないときは、利用者の依頼で、下書き・作業中・回答待ち・未読に関係なく、ただタスクが並んでいるだけの画面にする。下書き → チャット（最後に動いた順 `byActive`）を 1 つの並びにする（`FlatTasks`。まとまりは状態で分けず、段に分けるなら段だけで分ける `by: [lanes]`、分けなければ見出しのないまとまり 1 つ `by: []`）。ボードはカードを幅に合わせて何列にも折り返し（`.flat-tasks-grid`）、リストは 1 列の行。アーカイブ済みはいちばん下の閉じたまとまり（開閉は段ごと、段がなければ `flat/archived`）。状態はカードの点と文でだけ分かる。検索・絞り込み・段はそのまま使え、見出しの名前は「タスク」になる。

## 列とカード

- 状態の列 1 本は `StateColumn`（見出し `ColumnHead`（色の点・名前・件数・右端の操作。件数はアーカイブしていないものだけ。色の点・名前・件数は列の色の札（共通の `ui/ToneChip.tsx`）に入れ、文字・枠・薄い地をその列の色（`COLUMN_TONE`。下書きは `DRAFT_TONE` の灰）にする。グループのボードの見出しも同じ札で、グループの色 `ChatGroup.hue`（サイドバー・タブのまとまりと同じ）、「No Group」は灰。利用者の依頼）＋ カード ＋ いちばん下の閉じたまとまり `ArchivedFold`）。既読の列には `ArchiveAllButton`（確かめてから、列のチャットをすべてアーカイブ）。いちばん左の「下書き」の列は `DraftColumn`（まだ送っていない新しいチャット。新しいチャットは見出しの「新規」から始めるので、列に＋は置かない）。列の＋は、その列に意味があるとき（グループのボード）だけ置く。
- アーカイブ済みのチャットは、列・まとまりのいちばん下の閉じたまとまり `ArchivedFold`（`ui/`。サイドバーの子チャット・入力欄の上の一覧と共通）に分ける（サイドバーと同じ見出し。開閉はボード・段・列ごとに覚える。中のカードは薄く `.archived`）。カンバンのリスト表示では、アーカイブ済みを状態のまとまりごとには畳まず、いちばん下の 1 つのまとまり `ArchivedListSection` にまとめ、その中を状態ごとに分ける（`StateColumn` の `foldArchived={false}`。下書きはアーカイブできないので分けない）。
- カードとリストの行の描き方は `useBoardCards`（`card` / `row`。アーカイブの印と「回答 n件」（`pendingCount`）はどのボードでもここで付け、ボードごとの差分は `classFor` / `style` / `projectName` / `openTitle` / `drag` だけ。右のパネルで表示中なら選択中）。操作は `chatCardProps`（クリック・Enter で開く / 右クリックでメニュー / ドラッグはグループのボードと全プロジェクトのボードのグループの列だけ。カードの中のボタンを押したときは開かない）、右クリックは `useCardMenu`（開いている間はパネルを Esc で閉じない）。中身は `ChatCardContent` / `ChatRowContent`（作業中のまま未読なら「未読あり」）。
- 下書きのカード（`DraftCards`）の色・枠はほかのカードと同じ（目立たせない）。書いている途中の文があれば初めの 3 行を出し、押すとその欄で開く・右クリックで開く・削除。全プロジェクトのボードでは右上にプロジェクトのバッジ（`showProject`）。
- チャットはどちらのボードもチャットの店（`useChats`）から読み、アーカイブ済みを出すときだけそれも読む。

## 絞り込み

- アーカイブでの絞り込みは `ArchiveFilterSelect`（すべて / 未アーカイブ / アーカイブ済み。`archiveFilter.ts` の `useArchiveFilter` / `archiveMatches`）。アーカイブ済みを出すかはサイドバー・右のパネルのタブと共通の `SIDEBAR_SHOW_ARCHIVED`（`useShowArchivedChats`）で連動し、「未アーカイブ」を選ぶとどこでも隠し、「すべて」「アーカイブ済み」を選ぶとどこでも出す（値は `linkedArchiveFilter`）。「アーカイブ済みだけ」はボードの中だけの絞り込みとして、カンバン `BOARD_ARCHIVE_FILTER`・グループのボード `GROUP_BOARD_ARCHIVE_FILTER` に別々に覚える。絞り込み中の色（緑の枠）は、アーカイブ済みだけに絞っているときだけ。
- カンバンの絞り込み・候補・段は `useKanbanFilters`（アーカイブ・作業場所・名前の検索）/ `useWorktreeChoices`（ブランチ名で出し、フォルダが消えたものは「フォルダなし」と添える）/ `useKanbanLanes`、出すチャットは `useKanbanChats`（純粋関数 `kanbanChats`。全プロジェクトのボードではしまったプロジェクトの分を出さない）。カンバンにプロジェクトの絞り込みは置かない（見出しの名前 `ProjectSwitcher` から切り替える）。
- 名前で探す検索欄は見出しの `.board-search`（⌘F。`useChatSearch`）。右のボタンでチャットの中の文言の全文検索（⌘⇧F。`openContentSearch`）を開く。

## 見出し（ツールバー）と外枠

- 外枠は `BoardShell`（ツールバー `BoardHeader` → 失敗の文 → ボードの中身（`.board-main`）と右のパネル（プロジェクトのボードだけ。`rightPanel` に `useBoardPanel` を渡す）→ カードの右クリックのメニュー `ChatMenu`）。
- ツールバー（新規・表示・グループの作成・検索などの帯。部品は `BoardHeader`。画面の文言では「見出し」と呼ばない）は道具を概念ごとのまとまりに入れる: 左に 主な操作（新規）→ 表示（新規のすぐ右にボード / リストの切り替え → リストの行 → 列の分け方（状態 / グループなど）→ 段。利用者の依頼で、前は列の分け方が先頭だった）→ 整える（グループを作成）→ 探す・絞り込む、右にパネルの開閉（`PanelToggle`。右のパネルのあるプロジェクトのボードだけ）。ブラウザ・ターミナルはツールバーに置かず、パネルのタブの列から開く。名前（全プロジェクトの画面だけ。`heading`）があるときだけ道具との間を広げ、名前のないプロジェクトの画面では道具をボード・パネルの左端にそろえる。
- ツールバーはいつも横幅いっぱいの上に置き、右のパネルはその下から始まる（パネルがボードを覆っても、横幅いっぱいにしても見える）。置き方の設定は持たない（以前の「パネル優先」= パネルを上端まで伸ばしてツールバーをボードの側だけに出す形はやめた）。チャットタブに分けるとき（`CHAT_PLACEMENT` が `separate`）はボードに右のパネルがないので、並べ方の違いはそもそも出ない。
- 狭いときの並べ方は `@container` で書く（真ん中の画面の幅は、ウィンドウより欄の幅で変わるため）: ツールバーは `.board` の幅で 1120px 以下でボタンの文字を隠し、600px 以下で 2 段に。列は `board-main` の幅で 420px 以下なら 1 本ずつめくる。

## グループのボード（`GroupBoard`）

列 = グループ、カード = チャット。状態と操作は `useGroupBoard`（グループを作る・名前を変える・削除する（「…」メニュー `useGroupMenu`）、列へのドロップ（チャットを移す・列を並べ替える `useGroupDrop`。サイドバーからほかのプロジェクトのチャットを落とすと、確かめてからこのプロジェクトへ移してその列のグループへ入れる（`onForeignChat` → `moveDroppedChatToProject`）。作業中のチャットは落とせず、列を赤い点線にしてカーソルの横に理由を出す（`foreignBlockedBy`。見た目は `dropClass`））、名前の検索、アーカイブでの絞り込み、失敗の文）。列・まとまりは `GroupSections`、見出しは `GroupColumnHead`（ドラッグで並べ替え・名前のダブルクリックで名前を変える・右クリックと「…」でメニュー・＋でそのグループに新しいチャット）。「No Group」も見出しのドラッグでグループの間へ並べ替えられる（ボード・リストとも。並べ替えの並びの中の ID は `UNGROUPED_SORT_ID`（0）で、`useGroupDrop` に `ungroupedAt` を渡す）。グループの並びは今までどおり DB（`api.reorderGroups`。変わったときだけ）、「No Group」の位置（前にあるグループの数）はプロジェクトごとに画面に覚える（`groupBoardUngroupedAt`。ボード・リスト・サイドバーで共通。覚えていなければボードは先頭・リストとサイドバーはいちばん下。並べ方は純粋関数の `features/group/groupOrder.ts` の `ungroupedPosition` / `orderGroupBuckets`（サイドバーと共有するので group に置く）で、段に分けたときの段の順も同じ）。「グループを作成」（`GroupCreateForm`）は、No Group の位置によらず、ボードはいちばん右・リストはいちばん下（`GroupSections` の後ろ。前はいちばん後ろの自分で作ったグループのすぐ後ろで、No Group を後ろへ移すとその前に挟まった。ツールバーの「グループを作成」はそのまま）に、リストと同じ点線の枠の短い 1 つのボタン（高さ 40px。枠の中のどこを押しても作る。ボードの列も上に寄せて伸ばさない）で置く（前のボードは列の高さいっぱいの枠の中に小さなボタンがあり、点線の指定も後ろの `.board-column` に負けて実線だった）。サイドバーから来たグループはハイライトする（`GROUP_FLASH_EVENT`。表示中のグループでも、もう一度）。
