## 音声入力の設定（`VoiceSettings`）

利用者の依頼で、使いやすさと、無料か有料かが分かることを考えて作り直した。変えたらその場で保存する（保存のボタンはない。見出しの右に「変えるとすぐ保存されます」→「保存しました」。前は保存を押すまで効かず、「変更は保存してから効きます」と出していた）。上から:

- いちばん上のカード（`VoiceHero`）: 「チャット欄で音声入力を使う」のスイッチ（`.voice-switch`）と、いま使えるか（使えます / 準備が必要です — 理由 / オフ — スイッチを入れると…）・使い方の一言（1 回押し・長押し・波形の音声モード）。使えるときは枠とアイコンを緑に。前は状態のカードとチェックが別に並び、オフのときの理由が「設定の「音声入力」でオンにしてください」と設定の中で設定を指していた。
- 文字起こしの方法: 3 枚のカード（`VoiceProviderCard`。読み上げの声のカードと共通。`voiceOptions.ts` の `VOICE_PROVIDER_INFO`）に名前・料金の札（この Mac（whisper）・macOS の音声認識 = 「無料」の緑、OpenAI = 「有料（使った分だけ）」の注意の色 `.voice-price`）・ひとこと・良いところ ✓ と気を付けるところ −（料金の目安・音声を外に送るか・準備の手間・聞き取りの正確さ）。macOS の音声認識（利用者の依頼で選べるようにした。初めの値は「この Mac（whisper）」のまま）は、入れるものがなく速いが、whisper より聞き取りが劣ることがある、と書く。
- 話す言語。
- 選んだ方法の準備を手順に分け、済んだ手順は番号を緑の ✓ にする（`VoiceStep`）。この Mac（`VoiceLocalSetup`）は ① whisper.cpp と ffmpeg（見つかった場所。なければ `brew install whisper-cpp ffmpeg` とコピー・確かめ直す）② モデルを選んでダウンロード（「どれも無料」の札。`VoiceModelList`: 精度と速さの 4 段の目盛り（コアの `WHISPER_MODELS` の `accuracy` / `speed`）・おすすめ・ダウンロードのボタンに大きさ・進み具合・削除。選んだのにまだなら「使うにはダウンロードしてください」。進み具合は店の `useVoiceStatus` がサーバーの知らせでその場で直す）。macOS の音声認識（`VoiceMacosSetup`）は入れるものがないので、確かめた結果を見せるだけ: ① この Mac で使えるか（macOS 26 以上。使えなければ、ほかの方法を選ぶよう案内。確かめ直す）② 話す言語のモデル（起こす言語と地域「日本語（ja-JP）」・モデルが Mac に入っているか。なければ、はじめて使うときに macOS が落とす。「自動で判別」のときは Mac の言語で起こすと添える。対応していない言語なら、話す言語を変えるよう案内）。OpenAI（`VoiceOpenAiSetup`）は ① API キー（`OpenAiKeyField`。保存したら「保存済み」とだけ出し、二度と表示しない。ほかの設定とは別に、その場で保存する）② モデル（料金の目安 1 分あたり・10 分あたりの付いたカード。`OPENAI_MODEL_INFO`。料金は 2026 年 11 月時点の公表価格の目安で、そう添える）。OpenAI 互換のサーバーの Base URL と一覧にないモデル名は「詳しい設定」に畳み（使っていればはじめから開く）、打つたびではなく欄の外を押した・Enter で保存する（`CommitInput`）。
- 読み上げ（音声モード）（`VoiceSpeechSettings`）: 声の方法の 2 枚のカード（`VOICE_TTS_PROVIDER_INFO`。この Mac の声 = 「無料」/ OpenAI の声 = 「有料（使った分だけ）」と 1 分あたり約 $0.015 の目安）・声（この Mac の声は話す言語の声の一覧（`speechSynthesis` の `voiceschanged` で読み直す）と「話す言語の既定の声」、OpenAI は `OPENAI_TTS_VOICES`）・速さ（`VOICE_TTS_RATES`）・「試しに聞く / 止める」（`Speaker` で見本の文を読む）。OpenAI の声で API キーがまだなく、文字起こしが「この Mac」のときは、ここにも `OpenAiKeyField` を出す（キーは文字起こしと共通）。
